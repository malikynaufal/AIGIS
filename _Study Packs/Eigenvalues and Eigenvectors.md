# 🔢 Eigenvalues & Eigenvectors

Eigenvalues and eigenvectors reveal the fundamental structure of linear transformations — the directions that remain unchanged and the factors by which they are scaled. They are essential for PCA, vibration analysis, stability analysis, geodetic error ellipses, and solving systems of differential equations.

> **Indonesian glossary (Glosarium):** nilai eigen = eigenvalue, vektor eigen = eigenvector, polinomial karakteristik = characteristic polynomial, diagonalisasi = diagonalization, dekomposisi nilai singular = singular value decomposition (SVD), ruang eigen = eigenspace.

---

## 1. Core Definition

For a square matrix $\mathbf{A} \in \mathbb{R}^{n \times n}$, a scalar $\lambda$ is an **eigenvalue** and $\mathbf{v} \neq \mathbf{0}$ is the corresponding **eigenvector** if:

$$\mathbf{A}\mathbf{v} = \lambda\mathbf{v}$$

Rearranging:

$$(\mathbf{A} - \lambda\mathbf{I})\mathbf{v} = \mathbf{0}$$

For a non-trivial solution ($\mathbf{v} \neq \mathbf{0}$) to exist, we need:

$$\det(\mathbf{A} - \lambda\mathbf{I}) = 0$$

This is the **characteristic equation**.

---

## 2. Finding Eigenvalues

### 2.1 Characteristic Polynomial

For an $n \times n$ matrix $\mathbf{A}$:

$$p(\lambda) = \det(\mathbf{A} - \lambda\mathbf{I}) = (-1)^n \lambda^n + c_{n-1}\lambda^{n-1} + \cdots + c_1\lambda + c_0$$

Solve $p(\lambda) = 0$ to find all eigenvalues.

**For a $2 \times 2$ matrix:**

$$\mathbf{A} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

$$\lambda^2 - \text{tr}(\mathbf{A})\lambda + \det(\mathbf{A}) = 0$$

$$\lambda = \frac{\text{tr}(\mathbf{A}) \pm \sqrt{[\text{tr}(\mathbf{A})]^2 - 4\det(\mathbf{A})}}{2}$$

### 2.2 Properties of Eigenvalues

| Property | Formula |
|----------|---------|
| Sum of eigenvalues | $\sum \lambda_i = \text{tr}(\mathbf{A})$ (trace) |
| Product of eigenvalues | $\prod \lambda_i = \det(\mathbf{A})$ |
| Eigenvalues of $\mathbf{A}^k$ | $\lambda_i^k$ |
| Eigenvalues of $\mathbf{A}^{-1}$ | $1/\lambda_i$ (if $\mathbf{A}$ invertible) |
| Eigenvalues of $\mathbf{A} + c\mathbf{I}$ | $\lambda_i + c$ |
| Real symmetric $\mathbf{A}$ | All eigenvalues are real |
| Positive definite $\mathbf{A}$ | All eigenvalues are positive |

## 3. Finding Eigenvectors

For each eigenvalue $\lambda$, solve the homogeneous system:

$$(\mathbf{A} - \lambda\mathbf{I})\mathbf{v} = \mathbf{0}$$

The set of all eigenvectors for eigenvalue $\lambda$ (plus $\mathbf{0}$) forms the **eigenspace** $E_\lambda = \ker(\mathbf{A} - \lambda\mathbf{I})$.

**Process:**
1. Substitute $\lambda$ into $\mathbf{A} - \lambda\mathbf{I}$
2. Row-reduce to echelon form
3. Find the null space (free variables give the eigenvector components)
4. Normalize if needed: $\|\mathbf{v}\| = 1$

### 3.1 Algebraic vs Geometric Multiplicity

- **Algebraic multiplicity** ($m_a$): number of times $\lambda$ appears as a root of $p(\lambda)$
- **Geometric multiplicity** ($m_g$): dimension of $E_\lambda$ = number of linearly independent eigenvectors for $\lambda$

Always: $1 \leq m_g \leq m_a$

**Diagonalizability:** $\mathbf{A}$ is diagonalizable iff $m_g = m_a$ for every eigenvalue.

## 4. Matrix Diagonalization

### 4.1 Diagonalization

If $\mathbf{A}$ has $n$ linearly independent eigenvectors, then:

$$\mathbf{A} = \mathbf{P}\mathbf{D}\mathbf{P}^{-1}$$

where:
- $\mathbf{P} = [\mathbf{v}_1 | \mathbf{v}_2 | \cdots | \mathbf{v}_n]$ (matrix of eigenvectors)
- $\mathbf{D} = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$ (diagonal matrix of eigenvalues)

### 4.2 Powers of Matrices

$$\mathbf{A}^k = \mathbf{P}\mathbf{D}^k\mathbf{P}^{-1}$$

Since $\mathbf{D}^k = \text{diag}(\lambda_1^k, \lambda_2^k, \ldots, \lambda_n^k)$, computing $\mathbf{A}^k$ reduces to raising scalars to a power.

### 4.3 Matrix Exponential

$$e^{\mathbf{A}t} = \mathbf{P}e^{\mathbf{D}t}\mathbf{P}^{-1} = \mathbf{P}\,\text{diag}(e^{\lambda_1 t}, \ldots, e^{\lambda_n t})\mathbf{P}^{-1}$$

Used for solving linear ODE systems: $\dot{\mathbf{x}} = \mathbf{A}\mathbf{x}$.

### 4.4 Spectral Decomposition

For a symmetric matrix $\mathbf{A} = \mathbf{Q}\mathbf{\Lambda}\mathbf{Q}^T$ (since $\mathbf{Q}^{-1} = \mathbf{Q}^T$ for orthogonal matrices):

$$\mathbf{A} = \sum_{i=1}^n \lambda_i \mathbf{q}_i\mathbf{q}_i^T$$

where $\mathbf{q}_i$ are orthonormal eigenvectors.

---

## 5. Symmetric Matrices — Special Properties

Real symmetric matrices have exceptional properties:

| Property | Consequence |
|----------|------------|
| All eigenvalues are real | No complex eigenvalues |
| Eigenvectors for distinct eigenvalues are orthogonal | Can always choose orthogonal eigenvectors |
| Always diagonalizable | $\mathbf{A} = \mathbf{Q}\mathbf{\Lambda}\mathbf{Q}^T$ exists |
| Positive definite iff all $\lambda_i > 0$ | Key for covariance matrices |

**Covariance matrix properties:**
- Symmetric by definition ($\mathbf{C} = \mathbf{C}^T$)
- Positive semi-definite ($\lambda_i \geq 0$)
- Eigenvalues represent variance along principal directions
- Eigenvectors define the axes of the **error ellipse**

## 6. Singular Value Decomposition (SVD)

### 6.1 Definition

Any matrix $\mathbf{A} \in \mathbb{R}^{m \times n}$ can be decomposed as:

$$\mathbf{A} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^T$$

where:
- $\mathbf{U} \in \mathbb{R}^{m \times m}$: orthogonal matrix (left singular vectors)
- $\mathbf{\Sigma} \in \mathbb{R}^{m \times n}$: diagonal matrix of singular values $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$
- $\mathbf{V} \in \mathbb{R}^{n \times n}$: orthogonal matrix (right singular vectors)

### 6.2 Relationship to Eigenvalues

The singular values of $\mathbf{A}$ are the square roots of the eigenvalues of $\mathbf{A}^T\mathbf{A}$:

$$\sigma_i = \sqrt{\lambda_i(\mathbf{A}^T\mathbf{A})}$$

The columns of $\mathbf{V}$ are eigenvectors of $\mathbf{A}^T\mathbf{A}$, and the columns of $\mathbf{U}$ are eigenvectors of $\mathbf{A}\mathbf{A}^T$.

### 6.3 Truncated SVD (Low-Rank Approximation)

Keep only the top $k$ singular values:

$$\mathbf{A} \approx \mathbf{U}_k \mathbf{\Sigma}_k \mathbf{V}_k^T$$

This is the best rank-$k$ approximation to $\mathbf{A}$ in both the Frobenius and spectral norms (Eckart-Young theorem).

### 6.4 Pseudoinverse (Moore-Penrose)

$$\mathbf{A}^+ = \mathbf{V}\mathbf{\Sigma}^+\mathbf{U}^T$$

where $\mathbf{\Sigma}^+$ replaces each non-zero $\sigma_i$ with $1/\sigma_i$.

**Use:** Solving $\mathbf{Ax} = \mathbf{b}$ in the least-squares sense: $\hat{\mathbf{x}} = \mathbf{A}^+\mathbf{b}$.

## 7. Applications in Geodesy

### 7.1 Error Ellipse from Covariance Matrix

Given the $2 \times 2$ covariance matrix $\mathbf{C} = \begin{pmatrix} \sigma_x^2 & \sigma_{xy} \\ \sigma_{xy} & \sigma_y^2 \end{pmatrix}$:

- **Eigenvalues** $\lambda_1, \lambda_2$ give the semi-axis lengths: $a = \sqrt{\lambda_1}$, $b = \sqrt{\lambda_2}$
- **Eigenvectors** give the orientation of the principal axes (rotation angle)
- The error ellipse at confidence level $\alpha$ uses $k_\alpha\sqrt{\lambda_i}$ (e.g., $k_{95\%} \approx 2.447$ for 2D)

### 7.2 Principal Component Analysis (PCA)

In geodesy, PCA identifies dominant patterns of deformation from GNSS time series:

1. Compute covariance matrix of position time series
2. Eigenvalues give variance explained by each component
3. Eigenvectors give the direction of maximum variance

### 7.3 Network Design and Condition Analysis

Eigenvalue analysis of the normal equation matrix $\mathbf{N} = \mathbf{A}^T\mathbf{P}\mathbf{A}$:
- Small eigenvalues indicate poorly determined directions
- Condition number $\kappa = \lambda_{\max}/\lambda_{\min}$ measures numerical stability
- If $\kappa$ is large, the network is ill-conditioned

### 7.4 Strain Analysis

The strain tensor $\boldsymbol{\varepsilon}$ in geodetic deformation analysis:

$$\boldsymbol{\varepsilon} = \begin{pmatrix} \varepsilon_{xx} & \varepsilon_{xy} \\ \varepsilon_{xy} & \varepsilon_{yy} \end{pmatrix}$$

- Eigenvalues = principal strains (maximum and minimum)
- Eigenvectors = principal strain directions

### 7.5 Coordinate Transformation (Helmert)

The similarity matrix can be analyzed via eigenvalues to separate scaling, rotation, and shear effects.

## 8. Computational Methods

### 8.1 Power Iteration

Find the dominant eigenvalue $\lambda_1$ (largest magnitude):

1. Start with random $\mathbf{v}_0$
2. Iterate: $\mathbf{w} = \mathbf{A}\mathbf{v}_k$, $\mathbf{v}_{k+1} = \mathbf{w}/\|\mathbf{w}\|$
3. $\lambda_1 \approx \mathbf{v}_k^T \mathbf{A} \mathbf{v}_k$

**Convergence:** Linear, rate $|\lambda_2/\lambda_1|$.

### 8.2 QR Algorithm

For finding all eigenvalues simultaneously:

1. Set $\mathbf{A}_0 = \mathbf{A}$
2. Iterate: $\mathbf{Q}_k\mathbf{R}_k = \text{QR}(\mathbf{A}_k)$, $\mathbf{A}_{k+1} = \mathbf{R}_k\mathbf{Q}_k$
3. $\mathbf{A}_k$ converges to an upper triangular matrix with eigenvalues on the diagonal

**With shifts** (Wilkinson shift) for faster convergence.

### 8.3 Jacobi Method (for Symmetric Matrices)

Repeatedly apply Givens rotations to zero out off-diagonal elements:

$$\mathbf{A}_{k+1} = \mathbf{J}_k^T \mathbf{A}_k \mathbf{J}_k$$

where $\mathbf{J}_k$ is a rotation matrix that zeros the $(p,q)$ element. The accumulated rotations $\prod \mathbf{J}_k$ converge to the eigenvector matrix.
