### Essential Python Libraries
| Library | Purpose | Installation |
|---------|---------|--------------|
| **NumPy** | Array operations, linear algebra, random numbers | `pip install numpy` |
| **SciPy** | Integration, optimization, signal processing, stats | `pip install scipy` |
| **Matplotlib** | 2D/3D plotting and visualization | `pip install matplotlib` |
| **SymPy** | Symbolic mathematics (algebra, calculus, ODEs) | `pip install sympy` |
| **pandas** | Data structures for tabular/physics data | `pip install pandas` |
| **scikit-learn** | Machine learning | `pip install scikit-learn` |
| **Numba** | Just-in-time compilation for speed | `pip install numba` |
| **Cython** | C extensions for Python | `pip install cython` |
| **mayavi** | 3D scientific visualization | `pip install mayavi` |
| **plotly** | Interactive web-based plots | `pip install plotly` |
