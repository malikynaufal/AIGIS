## Deskripsi Mata Kuliah

Praktikum Sistem Basisdata adalah kegiatan praktikum yang mendukung kuliah Sistem Basisdata. Mahasiswa akan belajar mengimplementasikan konsep-konsep teori basisdata secara praktis menggunakan perangkat lunak sistem manajemen basisdata (DBMS) seperti PostgreSQL, MySQL, atau SQLite. Praktikum ini fokus pada pembuatan database, manipulasi data, dan kueri SQL untuk data geospasial.

Dalam praktikum ini, mahasiswa akan mempraktikkan pembuatan skema database untuk data survei, memasukkan data pengukuran ke dalam basisdata, melakukan normalisasi tabel, serta mengeksekusi kueri kompleks untuk analisis data. Praktikum ini juga memperkenalkan ekstensi PostGIS untuk penanganan data geometri dan geografis, yang menjadi fondasi penting untuk mata kuliah Sistem Informasi Geografis.

Setiap sesi praktikum dirancang untuk mempersiapkan mahasiswa dalam pengelolaan data geospasial berbasis database dalam skala nyata. Mahasiswa diharapkan mampu mendesain skema database yang efisien, menjaga integritas data, dan melakukan operasi CRUD (Create, Read, Update, Delete) serta analisis spasial dasar.

## Topik Utama

### 1. Instalasi dan Konfigurasi DBMS
- Instalasi PostgreSQL/PostGIS atau MySQL
- Konfigurasi server dan client
- Manajemen pengguna dan hak akses

### 2. Desain dan Implementasi Skema
- Pembuatan tabel untuk data survei
- Normalisasi hingga 3NF
- Primary key, foreign key, dan constraint

### 3. SQL Lanjutan dan PostGIS
- Query SQL kompleks (JOIN, Subquery, View)
- Fungsi spasial PostGIS
- Indeks spasial dan optimasi query

## Tujuan Pembelajaran

1. Menginstal dan mengkonfigurasi DBMS untuk data geospasial
2. Merancang dan mengimplementasikan skema database survei
3. Menguasai SQL untuk manipulasi dan analisis data
4. Memanfaatkan ekstensi PostGIS untuk data geometri
