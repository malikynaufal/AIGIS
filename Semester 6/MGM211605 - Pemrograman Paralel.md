# MGM211605 — Pemrograman Paralel (Parallel Programming)

## Course Information
- **Course Code:** MGM211605
- **Course Name:** Pemrograman Paralel (Parallel Programming)
- **Credit Hours (SKS):** 3
- **Semester:** 6
- **Prerequisites:** MGM211206 — Pemrograman Lanjutan

## Course Description
Introduction to parallel computing concepts and programming techniques for multi-core and distributed systems. Students learn to design, implement, and optimize parallel algorithms for various computing platforms.

## Key Topics

### Parallel Programming Paradigms
- Parallel computing models: shared memory vs. distributed memory
- Threads and parallelism: synchronization and mutual exclusion
- Message Passing Interface (MPI) and distributed memory programming
- OpenMP for shared memory parallelism
- CUDA programming for GPU acceleration

### Threading and Synchronization
- Creating and managing threads
- Race conditions and deadlocks
- Critical sections and synchronization primitives
- Monitor locks and semaphores
- Condition variables and barriers
- Thread-safe data structures

### Message Passing
- Point-to-point communication: send, receive, buffered I/O
- Collective communication: broadcast, reduce, gather, scatter
- MPI programming for distributed memory systems
- Hybrid parallel programming: MPI + OpenMP
- Performance analysis and tuning

### GPU Programming
- CUDA architecture and programming model
- Kernel programming and device memory management
- Parallel patterns for image processing and scientific computing
- GPU-accelerated linear algebra and matrix operations
- Performance optimization techniques

### Parallel Algorithms
- Parallel sorting and searching
- Parallel prefix and reduction operations
- Parallel graph algorithms
- Parallel numerical methods and linear algebra
- Load balancing and work distribution

### Performance Analysis
- Amdahl's law and speedup analysis
- Scalability and efficiency metrics
- Profiling and debugging parallel programs
- Weak vs. strong scaling
- Selection of appropriate parallel algorithms

## Learning Outcomes
- Design and implement parallel programs using multiple paradigms
- Apply synchronization primitives to ensure correctness in parallel programs
- Use MPI for distributed memory parallel programming
- Program GPUs for acceleration of computationally intensive tasks
- Analyze and optimize parallel program performance
- Select appropriate parallel algorithms for given problems
