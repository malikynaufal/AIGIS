# MGM211602 — Simulasi (Simulation)

## Course Information
- **Course Code:** MGM211602
- **Course Name:** Simulasi (Simulation)
- **Credit Hours (SKS):** 3
- **Semester:** 6
- **Prerequisites:** MGM211501 — Metode Numerik

## Course Description
Introduction to discrete-event simulation and Monte Carlo methods. Students learn modeling, implementation, and analysis of stochastic processes and complex systems using computational approaches.

## Key Topics

### Simulation Fundamentals
- Introduction to simulation modeling
- Deterministic vs. stochastic systems
- Discrete-event simulation vs. continuous simulation
- System boundaries and state descriptions
- Random number generation and pseudo-randomness
- Random variate generation (inverse transform, acceptance-rejection)
- Statistical validation of random number generators

### Monte Carlo Methods
- Introduction to Monte Carlo integration
- Importance sampling
- Variance reduction techniques
- Quasi-Monte Carlo methods
- Applications to estimation and optimization
- Financial modeling examples

### Discrete-Event Simulation
- Event scheduling and time advances
- Queueing models and server systems
- Interarrival and service time distributions
- Statistical analysis of simulation outputs
- Confidence intervals for simulation estimates
- Output analysis: steady-state vs. transient behavior

### Advanced Topics
- Discrete-event simulation of complex systems
- Queueing networks
- Facility location and layout planning
- Reliability modeling and redundancy analysis
- Statistical validation of simulation models
- Software packages (Arena, AnyLogic, Simula introduction)

### Applications
- Healthcare systems: hospitals, clinics, emergency departments
- Manufacturing: production lines, queueing systems
- Telecommunications: call centers, network traffic
- Transportation: traffic flow, airline scheduling
- Financial risk assessment and portfolio optimization

## Learning Outcomes
- Model stochastic systems using simulation techniques
- Implement Monte Carlo and discrete-event simulation algorithms
- Generate and analyze random variates
- Analyze simulation outputs and compute confidence intervals
- Use simulation to solve complex optimization problems
- Apply simulation methods to real-world systems across domains
