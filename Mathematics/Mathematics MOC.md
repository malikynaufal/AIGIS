## 🔬 Practical Geodesy Math

### **GNSS Positioning Math**
```
Pseudorange Equation:
ρ = ||r_sat - r_rx|| + c(dt_rx - dt_sat) + d_iono + d_tropo + noise

Design Matrix (linearized):
H = [ -cos(α)  -sin(α)  -1/sin(φ) : Seek facility common pattern

 Least Squares:
x→ = (H'H)⁻¹H'r
```

### **Coordinate Transform Math**
```
Geodetic → ECEF:
X = (N+h)cos(φ)cos(λ)
Y = (N+h)cos(φ)sin(λ)
Z = (N(1-e²)+h)sin(φ)

ECEF → Geodetic:
Use Newton-Raphson on Bowring's method → Converges in 2-3 iterations
```

### **Geoid Modeling Math**
```
Stokes' Integral:
N(p) = R/(4πγ) ∮_σ Δg·S(ψ)·dσ

Where:

- Δg = gravity anomaly

- S(ψ) = Stokes' function

- γ = normal gravity

- σ = unit sphere
```
