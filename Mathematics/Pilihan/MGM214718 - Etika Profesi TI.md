## Overview / Gambaran Umum

Etika Profesi TI adalah studi tentang prinsip moral dan profesional yang memandu praktik di bidang teknologi informasi. Dengan semakin besarnya dampak teknologi terhadap kehidupan manusia — termasuk privasi data, kecerdasan buatan, dan akses informasi geospasial — etika menjadi pilar yang tidak terpisahkan dari kompetensi teknis. Mata kuliah ini membahas kode etik profesi (ACM/IEEE), privasi data, kekayaan intelektual, dan tanggung jawab sosial insinyur/periset TI.

> **Catatan:** "Teknologi tidak memiliki moralitas — manusia di balik kode-lah yang memikul tanggung jawab." — *Prinsip Etika Profesi*

## 1. Kode Etik Profesi TI

### 1.1 ACM Code of Ethics and Professional Conduct (2018)

Prinsip utama:
1. **Berikan kontribusi positif kepada masyarakat dan kehidupan manusia.**
2. **Hindari kerusakan** — jangan menimbulkan risiko yang tidak perlu.
3. **Bersikap jujur dan terpercaya.**
4. **Hak milik intelektual** — hargai pekerjaan orang lain.
5. **Perlakukan semua orang dengan hormat.**

### 1.2 IEEE-CS/ACM Software Engineering Code (1999)

| Prinsip | Penjelasan |
|---------|------------|
| **Publik** | Bertindak demi kepentingan umum. |
| **Klien dan majikan** | Bertindak secara profesional untuk kepentingan terbaik klien. |
| **Produk** | Pastikan produk memenuhi standar dan tidak menyebabkan kerugian. |
| **Penilaian** | Hanya menilai hal-hal yang memiliki pengetahuan dan kompetensi. |
| **Manajemen** | Jadilah pemimpin etis. |
| **Profesi** | Tingkatkan reputasi dan integritas profesi. |
| **Rekan kerja** | Dukung dan hormati rekan kerja. |
| **Diri sendiri** | Tingkatkan kompetensi profesional secara berkelanjutan. |

## 2. Privasi Data

### 2.1 Prinsip Privasi (Fair Information Practices)

- **Pemberitahuan:** Informasikan pengguna tentang data yang dikumpulkan.

- **Pilihan/Persetujuan:** Beri pengguna kontrol atas data mereka.

- **Akses:** Pengguna dapat mengakses data yang dikumpulkan.

- **Keamanan:** Lindungi data dari akses tidak sah.

### 2.2 Regulasi Utama

| Regulasi | Yurisdiksi | Fokus |
|----------|-----------|-------|
| **GDPR** | Uni Eropa | Perlindungan data pribadi, *right to be forgotten* |
| **CCPA** | California, AS | Hak konsumen atas data pribadi |
| **UU PDP** | Indonesia | Perlindungan data pribadi (2022) |
| **HIPAA** | AS (kesehatan) | Privasi data medis |

### 2.3 Kasus Pelanggaran Privasi

Pelanggaran data geospasial sensitif: koordinat lokasi personel militer, lokasi fasilitas rahasia, data posisi individu yang dapat melacak aktivitas harian (location tracking). Ini berpotensi pelanggaran HAM jika disalahgunakan.

## 3. Kekayaan Intelektual (Intellectual Property)

| Bentuk IP | Durasi Perlindungan | Contoh |
|-----------|-------------------|--------|
| **Hak Cipta (Copyright)** | Hidup + 70 tahun (atau 50 tahun setelah kematian) | Kode program, artikel |
| **Paten** | 20 tahun | Algoritma baru, perangkat lunak unik (terbatas) |
| **Merek Dagang (Trademark)** | Tak terbatas (selama masih digunakan) | Logo, nama produk |
| **Hak Cipta Basis Data** | 15-25 tahun | Dataset spasial, database |
| **Trade Secret** | Selama tetap rahasia | Kode sumber, model ML |

**Isu Penting:**

- **Open Source vs Proprietary:** Lisensi GPL, MIT, Apache mempengaruhi hak penggunaan kode.

- **AI-Generated Content:** Siapa pemilik hasil yang dihasilkan oleh AI? (Perdebatan hukum aktif).

- **Data Spasial Negara:** Regulasi data spasial di Indonesia (Permen ATR/Kepala BPN No. 12/2018).

## 4. Tanggung Jawab Sosial dan Sustainability

### 4.1 Environmental Computing

- Dampak lingkungan pusat data (carbon footprint).

- Green computing: optimasi energi, hardware tahan lama.

### 4.2 Digital Divide

- Kesenjangan akses informasi antara kota dan desa.

- Pentingnya layanan geospasial yang inklusif untuk semua.

### 4.3 Bias dalam AI

- Model machine learning dapat memperkuat diskriminasi jika data training tidak representatif.

- Contoh: sistem pengenalan wajah dengan akurasi berbeda berdasarkan etnis.

## 5. Studi Kasus: Etika Pengumpulan Data Geospasial

**Situasi:** Perusahaan survei dipekerjakan untuk pemetaan kawasan hutan, tetapi data yang dikumpulkan juga memperlihatkan lokasi permukiman masyarakat adat terpencil.

**Analisis Etika:**

- Apakah masyarakat adat sudah memberikan *informed consent*? (Hak Inform)

- Data sensitif ini bolehkah dishare ke pihak ketiga? (Privasi)

- Jika data bocor, bagaimana dampaknya terhadap komunitas? (Non-maleficence)

- Siapa yang bertanggung jawab jika data disalahgunakan? (Akuntabilitas)

**Kesimpulan Etis:** Data harus diklasifikasikan sebagai *sensitive*, dienkripsi, dan tidak dibagikan tanpa persetujuan tegas dari masyarakat adat.
