## Overview / Gambaran Umum

Pembelajaran Mesin (Machine Learning) adalah sub-bidang AI yang memberikan komputer kemampuan untuk belajar dari data tanpa diprogram secara eksplisit. Teknik ini kini mendominasi pemrosesan data geospasial, mulai dari prediksi deformasi tanah hingga klasifikasi penggunaan lahan satelit. Mata kuliah ini mencakup pembelajaran terawasi (supervised: regresi, klasifikasi, SVM), tidak terawasi (unsupervised: clustering, PCA), serta pengenalan jaringan saraf tiruan (neural networks).

> **Catatan:** "ML bukan tentang 'belajar' seperti manusia, melainkan optimisasi fungsi matematika untuk meminimalkan error prediksi." — *Prinsip ML*

---

## 1. Pembelajaran Terawasi (Supervised Learning)

- **Regresi Linear/Logistik:** Memprediksi nilai kontinu atau kategori.

- **Decision Trees / Random Forest:** Model berbasis aturan yang sangat robust.

- **SVM (Support Vector Machines):** Mencari margin pemisah maksimal antar kelas.

## 2. Pembelajaran Tidak Terawasi (Unsupervised Learning)

- **Clustering (K-Means, DBSCAN):** Mengelompokkan data tanpa label (misal: clustering stasiun GNSS dengan pola pergerakan serupa).

- **Reduksi Dimensi (PCA - Principal Component Analysis):** Mengurangi dimensi data sambil mempertahankan variansi (penting untuk hyperspectral imagery).

## 3. Jaringan Saraf Tiruan (Neural Networks)

- **Arsitektur:** Input layer, hidden layer, output layer.

- **Backpropagation:** Algoritma untuk memperbarui bobot berdasarkan error (gradient descent).

## 4. Evaluasi

- **Train/Test Split:** Memisahkan data untuk mencegah *overfitting*.

- **Cross-Validation (k-fold):** Validasi model yang lebih handal.

- **Matriks:** Accuracy, Precision, Recall, F1-Score, RMSE.
