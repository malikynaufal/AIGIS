# MGM211501 — Metode Numerik (Numerical Methods)

## Course Information

- **Course Code:** MGM211501

- **Course Name:** Metode Numerik (Numerical Methods)

- **Credit Hours (SKS):** 3

- **Semester:** 5

- **Prerequisites:** MGM211401 — Kalkulus Numerik

## Course Description
Advanced numerical methods for optimization, root finding, and large-scale computational problems. Students learn advanced iterative algorithms, convergence analysis, and practical implementation strategies using Python/MATLAB.

## Key Topics

### Root Finding for Nonlinear Systems

- Fixed-point iteration and convergence conditions

- Newton's method for systems of equations

- Broyden's method (quasi-Newton)

- Homotopy continuation methods

- Convergence analysis: order and rate

### Unconstrained Optimization

- Line search methods: bisection, golden section, interpolation

- Gradient descent: convergence analysis, adaptive step size

- Newton and quasi-Newton methods (BFGS, L-BFGS)

- Conjugate gradient methods

- Trust region methods

- Global optimization: simulated annealing, genetic algorithms

### Constrained Optimization

- Lagrangian formulation and KKT conditions

- Interior point methods

- Active set methods

- Sequential quadratic programming (SQP)

- Linear programming: simplex method and interior point

- Duality in linear programming

### Matrix Computation

- Direct methods: Gaussian elimination, Cholesky, QR

- Iterative methods: Jacobi, Gauss-Seidel, SOR

- Sparse matrix storage and computation

- Eigenvalue computation: power method, inverse iteration, QR algorithm

- Singular value decomposition computation

- Matrix condition number estimation

### Computational Statistics

- Monte Carlo methods and random number generation

- Markov Chain Monte Carlo (MCMC): Metropolis-Hastings, Gibbs

- Bootstrap and resampling methods

- Numerical integration of probability distributions

- Statistical computing: confidence intervals by simulation

### Applications and Implementation

- Scientific computing libraries: NumPy, SciPy, PETSc

- Performance optimization: vectorization, caching

- Parallel numerical computing (introduction)

- Benchmarking and reproducible numerical experiments

## Learning Outcomes

- Implement advanced root finding algorithms for nonlinear systems

- Apply optimization methods to solve unconstrained and constrained problems

- Analyze convergence properties of iterative numerical algorithms

- Use sparse matrix methods for large-scale problems

- Implement Monte Carlo and MCMC sampling methods

- Solve real-world computational problems using scientific computing libraries
