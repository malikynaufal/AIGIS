# MGM211503 — Optimisasi (Optimization)

## Course Information

- **Course Code:** MGM211503

- **Course Name:** Optimisasi (Optimization)

- **Credit Hours (SKS):** 3

- **Semester:** 5

- **Prerequisites:** MGM211401 — Kalkulus Numerik; MGM211202 — Persamaan Diferensial

## Course Description
Mathematical and computational methods for optimization problems. Covers linear programming, nonlinear optimization, and convex optimization with applications in engineering, finance, and machine learning.

## Key Topics

### Optimization Fundamentals

- Problem formulation: objective function, constraints, feasible set

- Classification: linear vs. nonlinear, convex vs. nonconvex

- Optimal solutions: local vs. global, existence and uniqueness

- Constrained and unconstrained optimization

- Lagrangian duality and duality gap

### Linear Programming

- Formulation of LP problems

- Graphical method (2 variables)

- Simplex algorithm and its variants

- Duality in linear programming

- Sensitivity analysis and parametric programming

- Transportation and assignment problems

### Convex Optimization

- Convex sets and convex functions

- Second-order conditions and Hessians

- Strong duality in convex optimization

- Semidefinite programming (SDP) introduction

- Applications of convex optimization

### Nonlinear Optimization

- Unconstrained optimization: necessary and sufficient conditions

- Gradient descent and steepest descent

- Newton's method for optimization

- Conjugate gradient and quasi-Newton methods

- Trust region methods

- Penalty and barrier methods for constrained problems

- Sequential Quadratic Programming (SQP)

### Advanced Methods

- Genetic algorithms and evolutionary computation

- Particle swarm optimization

- Ant colony optimization

- Simulated annealing

- Multi-objective optimization (Pareto optimality)

- Applications in scheduling and logistics

### Practical Applications

- Portfolio optimization (Markowitz model)

- Facility location problems

- Resource allocation

- Scheduling and timetabling

- Parameter estimation and model fitting

## Learning Outcomes

- Formulate real-world problems as mathematical optimization problems

- Solve linear programs using the simplex method and duality

- Apply gradient and Newton methods to nonlinear optimization problems

- Understand convexity conditions and their implications

- Implement optimization algorithms in Python

- Evaluate and select optimization methods based on problem characteristics
