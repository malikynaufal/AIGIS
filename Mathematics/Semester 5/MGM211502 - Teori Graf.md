# MGM211502 — Teori Graf (Graph Theory)

## Course Information

- **Course Code:** MGM211502

- **Course Name:** Teori Graf (Graph Theory)

- **Credit Hours (SKS):** 3

- **Semester:** 5

- **Prerequisites:** MGM211102 — Aljabar Linear

## Course Description
Introduction to the mathematical theory of graphs and discrete structures. Covers fundamental graph concepts, traversal algorithms, and their applications in computer science, operations research, and combinatorial optimization.

## Key Topics

### Basic Graph Concepts

- Definition: vertices, edges, adjacency, incidence

- Graph representations: adjacency matrices, adjacency lists

- Types of graphs: directed, undirected, weighted, unweighted

- Paths, cycles, connectivity, trails, walks

- Degree sum formula and parity

- Eulerian and Hamiltonian graphs

### Graph Traversal Algorithms

- Depth-first search (DFS) and breadth-first search (BFS)

- Topological sorting of directed acyclic graphs (DAGs)

- Connected components algorithms

- Strongly connected components in directed graphs

- Biconnected components and articulation points

### Graph Theory Algorithms

- Shortest path algorithms: Dijkstra, Bellman-Ford

- Minimum spanning trees: Prim, Kruskal

- Maximum flow: Ford-Fulkerson, Edmonds-Karp

- Matching algorithms: bipartite matching

- Network flow and flow theory

- Minimum cut and max flow theorem

### Tree Algorithms

- Binary trees, heap trees, search trees

- Tree traversal: in-order, pre-order, post-order

- Balanced trees: AVL, red-black, B-trees

- Search tree algorithms: insertion, deletion, search

- Tree decomposition and packing

### Graph Theory Applications

- Social network analysis and centrality measures

- Scheduling problems (job sequencing)

- Transportation and network optimization

- Computer network design and routing

- Algorithm complexity analysis using graph theory

## Learning Outcomes

- Model problems as graphs and analyze structure

- Implement graph traversal and search algorithms

- Solve optimization problems using graph algorithms

- Analyze graph properties: connectivity, traversal, counting

- Design efficient algorithms for graph-related problems

- Understand the theoretical foundations of discrete optimization
