# MGM211505 — Visi Komputer (Computer Vision)

## Course Information

- **Course Code:** MGM211505

- **Course Name:** Visi Komputer (Computer Vision)

- **Credit Hours (SKS):** 3

- **Semester:** 5

- **Prerequisites:** MGM211105 — Pengantar Pemrograman; MGM211303 — Probabilitas

## Course Description
Introduction to fundamental concepts and techniques in computer vision and image processing. Students learn to represent, analyze, and understand visual information from digital images, focusing on both theoretical foundations and practical applications.

## Key Topics

### Image Representation and Fundamentals

- Digital image models: pixel formats, color spaces (RGB, HSV, YUV)

- Image acquisition and digitization

- Image pyramids, sampling, and aliasing

- Fourier transforms and frequency domain analysis

- Image quality: contrast, brightness, noise

- Morphological operations: dilation, erosion, opening, closing

### Edge Detection and Feature Extraction

- Gradient computation and edge detection (Sobel, Prewitt)

- Non-linear edge detection: Canny detector

- Hough transform for line and circle detection

- Feature detection: corner detection (Harris, Shi-Tomasi)

- Blob detection and local feature descriptors

- Scale-Invariant Feature Transform (SIFT) and ORB

### Pattern Recognition and Classification

- Introduction to machine learning for vision: supervised/unsupervised

- Support Vector Machines (SVM) for image classification

- K-means and hierarchical clustering for image segmentation

- K-nearest neighbors (KNN) for image database retrieval

- Batch and online learning for classification

### Object Detection and Tracking

- Region-based and sliding window detection

- Haar cascades and LBP features

- Deep learning basics for object detection (CNNs)

- Tracking algorithms: Kalman filter, particle filter

### Image Enhancement and Restoration

- Spatial filtering: convolution, deconvolution

- Frequency domain filtering: low-pass, high-pass filters

- Noise reduction and image denoising

- Histogram equalization and adaptive contrast enhancement

- Inpainting and image inpainting

### Applications and Case Studies

- Face recognition and verification

- OCR (Optical Character Recognition)

- Medical image analysis (MRI, CT)

- Robotics: visual navigation, object grasping

- Augmented reality and augmented virtuality

## Learning Outcomes

- Preprocess and enhance digital images for analysis

- Extract features and detect patterns using traditional computer vision methods

- Implement classification and clustering algorithms for image data

- Use deep learning approaches for object detection

- Apply computer vision techniques to real-world applications
