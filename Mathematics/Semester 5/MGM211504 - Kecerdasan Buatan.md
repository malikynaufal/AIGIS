# MGM211504 — Kecerdasan Buatan (Artificial Intelligence)

## Course Information
- **Course Code:** MGM211504
- **Course Name:** Kecerdasan Buatan (Artificial Intelligence)
- **Credit Hours (SKS):** 3
- **Semester:** 5
- **Prerequisites:** MGM211205 — Struktur Data dan Algoritma

## Course Description
Introduction to artificial intelligence covering search algorithms, knowledge representation, reasoning, and machine learning fundamentals. Students learn classical AI techniques and modern approaches to building intelligent systems.

## Key Topics

### Search and Problem Solving
- Problem representation: state space, operators, goals
- Uninformed search: BFS, DFS, IDDFS, bidirectional search
- Informed search: A*, greedy best-first, IDA*
- Heuristics: admissible and consistent
- Constraint satisfaction problems (CSPs)
- Backtracking search and constraint propagation
- Adversarial search: minimax, alpha-beta pruning

### Knowledge Representation and Reasoning
- Propositional logic: syntax, semantics, inference
- First-order logic (FOL): predicates, quantifiers
- Resolution and proof methods
- Bayesian reasoning: Bayes' theorem, belief networks
- Ontologies and semantic networks
- Description logics (introduction)

### Planning and Decision Making
- Classical planning: STRIPS, PDDL
- Partial order planning
- Reinforcement learning foundations: MDPs, value iteration
- Multi-attribute decision making
- Probabilistic graphical models

### Machine Learning Introduction
- Supervised learning: classification and regression
- Decision trees and random forests
- k-nearest neighbors (kNN)
- Naive Bayes classifier
- Support Vector Machines (SVM) overview
- Unsupervised learning: clustering, dimensionality reduction
- Evaluation metrics: accuracy, precision, recall, F1

### Natural Language Processing (Intro)
- Text preprocessing: tokenization, stemming, lemmatization
- Bag-of-words and TF-IDF
- Sentiment analysis basics
- Language models and word embeddings (introduction)
- Sequence labeling: HMM and CRF (overview)

### Ethics and Future of AI
- Bias and fairness in AI systems
- Transparency and explainability
- Responsible AI development
- History and future of AI research

## Learning Outcomes
- Implement classical search algorithms for problem solving
- Apply knowledge representation techniques for reasoning
- Build basic machine learning classifiers and regressors
- Understand and apply constraint satisfaction methods
- Formulate and solve planning problems
- Critically evaluate AI systems for ethical concerns
