# MGM211305 — Basis Data (Database Systems)

## Course Information
- **Course Code:** MGM211305
- **Course Name:** Basis Data (Database Systems)
- **Credit Hours (SKS):** 3
- **Semester:** 3
- **Prerequisites:** MGM211105 — Pengantar Pemrograman

## Course Description
Introduction to database concepts, design, implementation, and management. Students learn to model real-world information using relational data models, write SQL queries, and understand transaction processing and database security.

## Key Topics

### Database Concepts
- Data vs. information vs. knowledge
- Database models: hierarchical, network, relational
- RDBMS vs. NoSQL systems (brief introduction)
- Database administration and roles
- ACID properties: Atomicity, Consistency, Isolation, Durability
- Database architecture: clients, servers, middleware

### Relational Data Model
- Tables, rows, columns, schemas, and instances
- Keys: primary, foreign, candidate keys
- Relationships: one-to-one, one-to-many, many-to-many
- Entity-Relationship (ER) diagrams
- Normalization: 1NF, 2NF, 3NF, BCNF, 4NF
- Data dependency analysis and lossy decomposition
- Practical design methodology

### SQL (Structured Query Language)
- DML and DDL: SELECT, INSERT, UPDATE, DELETE, CREATE, DROP
- Query processing and execution plans
- Joins: inner, outer, self-joins, natural joins
- Set operations: UNION, INTERSECT, MINUS
- Grouping and aggregation functions
- Subqueries and correlated subqueries
- Window functions and CTEs (WITH clauses)
- Transaction control: COMMIT, ROLLBACK

### Database Design and Constraints
- Functional dependencies and normal forms
- Logical database design process
- Data integrity constraints
- Views: simple and complex views
- Security: user privileges and access control
- Triggers and stored procedures

### SQL Programming and Applications
- Python integration with databases (sqlite3, psycopg2)
- Connection pooling and transactions in Python
- Database isolation levels and concurrency
- Introduction to ORMs and query builders
- Exporting/importing data (CSV, JSON)
- Backup and recovery basics

## Learning Outcomes
- Design relational database schemas using ER diagrams
- Normalize data to eliminate redundancy
- Write complex SQL queries to extract and manipulate data
- Understand the concepts of transaction management
- Connect databases with Python applications
- Analyze database performance and optimize queries
