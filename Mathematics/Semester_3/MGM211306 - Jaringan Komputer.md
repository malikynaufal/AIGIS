# MGM211306 — Jaringan Komputer (Computer Networks)

## Course Information

- **Course Code:** MGM211306

- **Course Name:** Jaringan Komputer (Computer Networks)

- **Credit Hours (SKS):** 3

- **Semester:** 3

- **Prerequisites:** MGM211105 — Pengantar Pemrograman

## Course Description
Introduction to networking principles, protocols, and architecture. Students learn the TCP/IP stack, network programming, and practical skills for configuring, debugging, and analyzing network systems.

## Key Topics

### Network Fundamentals

- Types of networks: LAN, WAN, PAN, MAN

- Network topologies: star, bus, ring, mesh

- Client-server vs. peer-to-peer models

- Network devices: hubs, switches, routers, access points

- Internet backbone, ISPs, and connectivity

- Network performance: bandwidth, latency, throughput, jitter

### OSI and TCP/IP Models

- Seven-layer OSI model: functions and protocols per layer

- Four-layer TCP/IP model and correspondence to OSI

- Data encapsulation and de-encapsulation

- Protocol data units (PDUs) and frame formats

- Application layer services and interfaces

### Data Link and Physical Layers

- MAC addressing and Ethernet (IEEE 802.3)

- CSMA/CD and CSMA/CA

- Wireless networking standards (802.11a/b/g/n/ac)

- Error detection and correction techniques

- Data framing and byte stuffing

- Physical layer: modulation, multiplexing, transmission media

### Network and Transport Layers

- IP addressing (IPv4 and IPv6)

- Subnetting and CIDR

- Routing algorithms: distance vector, link state

- TCP and UDP: characteristics and differences

- TCP connection management, flow control (sliding window)

- Congestion control: slow start, fast recovery

### Application Layer Protocols

- HTTP/HTTPS and web protocols

- DNS and name resolution

- SMTP, POP3, IMAP for email

- FTP and file transfer protocols

- DHCP for dynamic address allocation

- SNMP and network management

### Network Programming and Security

- Socket programming: TCP and UDP (Python, C/Java)

- Client-server application development

- SSL/TLS for secure communications

- Firewalls, VPNs, and network security

- Network monitoring tools: Wireshark, tcpdump

- HTTP requests, REST APIs, and web sockets

## Learning Outcomes

- Describe the layered architecture of computer networks

- Configure and troubleshoot basic network setups

- Implement socket-based network programming in Python

- Analyze network traffic using packet capture tools

- Explain TCP/IP protocols and their interactions

- Apply network security principles to protect data in transit
