# MGM211105 — Pengantar Pemrograman (Introduction to Programming)

## Course Information

- **Course Code:** MGM211105

- **Course Name:** Pengantar Pemrograman (Introduction to Programming)

- **Credit Hours (SKS):** 3

- **Semester:** 1

- **Prerequisites:** None

## Course Description
First course in programming using Python. Students learn fundamental programming concepts including variables, control flow, functions, data structures, and basic algorithm design. The course emphasizes problem-solving skills and computational thinking through hands-on coding exercises and projects.

## Key Topics

### Programming Fundamentals

- Programming paradigms overview (imperative, declarative, OOP)

- Setting up Python development environment (VS Code, Jupyter)

- Variables, data types, and type conversion

- Operators: arithmetic, comparison, logical

- Input/output operations and string formatting

- Comments and code documentation

### Control Flow

- Conditional statements: if, elif, else

- Boolean logic and short-circuit evaluation

- for loops and while loops

- Loop control: break, continue, else clause

- Nested loops and loop patterns

- List comprehensions and generator expressions

### Functions and Modules

- Function definition, parameters, and return values

- Scope: local, enclosing, global (LEGB rule)

- Lambda functions and closures

- Recursion: base cases and recursive thinking

- Python modules and imports

- The `math`, `random`, and `datetime` modules

### Data Structures

- Lists: indexing, slicing, methods, list operations

- Tuples: immutability and packing/unpacking

- Dictionaries: key-value pairs, iteration, methods

- Sets: operations, membership testing, comprehensions

- Strings as sequences: formatting, methods, regex intro

- When to choose each data structure

### File I/O and Error Handling

- Reading and writing text files

- CSV file processing

- Context managers (with statement)

- Exception handling: try, except, finally

- Custom exceptions and error messages

- Working with JSON files

### Basic Algorithms and Problem Solving

- Algorithm design and pseudocode

- Linear and binary search algorithms

- Sorting: bubble sort, selection sort, insertion sort

- Time complexity intuition: O(n), O(n²), O(log n)

- Debugging strategies and techniques

- Introduction to testing

## Learning Outcomes

- Write Python programs to solve computational problems

- Implement control structures and functions correctly

- Choose appropriate data structures for given problems

- Read from and write to files using exception handling

- Implement basic searching and sorting algorithms

- Develop problem-solving and algorithmic thinking skills
