# MGM211604 — Pengolahan Citra (Image Processing)

## Course Information

- **Course Code:** MGM211604

- **Course Name:** Pengolahan Citra (Image Processing)

- **Credit Hours (SKS):** 3

- **Semester:** 6

- **Prerequisites:** MGM211501 — Metode Numerik

## Course Description
Comprehensive introduction to digital image processing techniques and algorithms. Students learn to analyze, enhance, and reconstruct digital images using mathematical and computational approaches.

## Key Topics

### Digital Image Fundamentals

- Image acquisition and digitization

- Image sampling and quantization

- Color spaces: RGB, HSV, YCbCr, CIELAB

- Image resolution, aspect ratio, and interpolation

- Digital image histogram analysis

### Spatial Domain Operations

- Point operations: intensity transformations

- Neighborhood operations: filtering, erosion, dilation

- Morphological operations: opening, closing, skeletonization

- Binary image processing and mathematical morphology

- Thresholding techniques

### Frequency Domain Operations

- Two-dimensional Fourier transform

- Frequency domain filtering: low-pass, high-pass filters

- Image sampling and aliasing in frequency domain

- Filter design and implementation

- Convolution and correlation theorems

### Transform-Based Methods

- Wavelet transforms: discrete wavelet transform (DWT)

- Hartley transform and applications

- Polynomial transform and curve fitting

- Radon and inverse Radon transforms

- Steganography and image watermarking

### Image Enhancement and Restoration

- Contrast stretching and histogram equalization

- Sharpening and smoothing filters

- Adaptive filtering and edge detection

- Noise models: salt-and-pepper, Gaussian, impulse

- Restoration techniques: deconvolution, Wiener filtering

### Feature Detection and Segmentation

- Edge detection algorithms: Sobel, Canny, Roberts

- Corner detection: Harris, Shi-Tomasi

- Interest point detection: SIFT, SURF, ORB

- Segmentation methods: region growing, clustering

- Active contours and snake algorithms

### Applications

- Medical imaging: MRI, CT scan analysis

- Remote sensing and satellite imagery

- Industrial inspection and quality control

- Forensic image enhancement

- Video processing and motion analysis

## Learning Outcomes

- Apply spatial and frequency domain filtering techniques

- Use transforms for image analysis and compression

- Implement thresholding and segmentation algorithms

- Enhance and restore digital images

- Detect and track features in images

- Apply image processing techniques to real-world problems
