# MGM211603 — Pembelajaran Mesin (Machine Learning)

## Course Information
- **Course Code:** MGM211603
- **Course Name:** Pembelajaran Mesin (Machine Learning)
- **Credit Hours (SKS):** 3
- **Semester:** 6
- **Prerequisites:** MGM211505 — Visi Komputer; MGM211402 — Statistika Matematika

## Course Description
Fundamental concepts and algorithms of machine learning, covering both theoretical foundations and practical implementations. Students learn to develop, evaluate, and apply machine learning models to solve real-world problems.

## Key Topics

### Supervised Learning
- Linear regression and ridge regression
- Logistic regression and classification
- Support vector machines (SVM)
- Decision trees and random forests
- Ensemble methods: bagging, boosting
- Neural networks: multi-layer perceptrons
- Model evaluation and selection
- Cross-validation and hyperparameter tuning

### Unsupervised Learning
- Clustering: k-means, hierarchical, DBSCAN
- Dimensionality reduction: PCA, t-SNE, UMAP
- Kernel methods and support vector clustering
- Anomaly detection: outlier detection, one-class SVM
- Generative models: Gaussian mixture models

### Advanced Topics
- Deep learning: CNN, RNN, transformer architectures
- Transfer learning and fine-tuning
- Natural language processing basics: word embeddings, text classification
- Reinforcement learning fundamentals: Q-learning, policy gradients
- Semi-supervised learning and active learning
- Model interpretability and explainable AI (XAI)

### Practical Implementation
- Python libraries: scikit-learn, TensorFlow, Keras
- Data preprocessing and feature engineering
- Hyperparameter optimization (grid search, Bayesian optimization)
- Model deployment and serving
- Ethical considerations in machine learning

## Learning Outcomes
- Implement supervised learning algorithms for prediction and classification
- Apply unsupervised learning techniques for clustering and dimensionality reduction
- Understand theoretical foundations of machine learning algorithms
- Evaluate and compare machine learning models using appropriate metrics
- Deploy machine learning solutions in production environments
- Address ethical and societal implications of AI systems
