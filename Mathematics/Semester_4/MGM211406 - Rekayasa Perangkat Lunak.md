# MGM211406 — Rekayasa Perangkat Lunak (Software Engineering)

## Course Information

- **Course Code:** MGM211406

- **Course Name:** Rekayasa Perangkat Lunak (Software Engineering)

- **Credit Hours (SKS):** 3

- **Semester:** 4

- **Prerequisites:** MGM211206 — Pemrograman Lanjutan

## Course Description
Introduction to systematic software development methodologies and practices. Students learn the Software Development Life Cycle (SDLC), requirements engineering, design patterns, testing strategies, and project management techniques for building reliable, maintainable software.

## Key Topics

### Software Development Life Cycle (SDLC)

- Waterfall, iterative, and incremental models

- Agile methodologies: Scrum, Kanban, XP

- DevOps culture and continuous integration/deployment

- Software process improvement (CMMI overview)

- Selecting appropriate process models

### Requirements Engineering

- Elicitation techniques: interviews, workshops, observation

- Requirements specification: functional vs. non-functional

- User stories, use cases, and acceptance criteria

- Requirements validation and traceability

- Prioritization methods (MoSCoW, Kano model)

- Requirements management and change control

### Software Design

- Architectural patterns: layered, microservices, event-driven

- Design principles: SOLID, DRY, KISS, YAGNI

- Design patterns (GoF): creational, structural, behavioral

- Domain-driven design (DDD) concepts

- UML diagrams: class, sequence, component, deployment

- API design and documentation (OpenAPI/Swagger)

### Implementation and Coding Standards

- Code quality metrics: cyclomatic complexity, coupling, cohesion

- Version control strategies: GitFlow, trunk-based development

- Code reviews and pair programming

- Static analysis and linting tools

- Documentation practices

### Testing and Quality Assurance

- Test pyramid: unit, integration, system, acceptance

- Test-driven development (TDD)

- Behavior-driven development (BDD)

- Unit testing frameworks (JUnit, PyTest, Jest)

- Mocking and test doubles

- Continuous integration pipelines

- Code coverage and mutation testing

### Software Maintenance and Evolution

- Technical debt and refactoring

- Legacy system modernization

- Release management and versioning (SemVer)

- Configuration management

- Monitoring, logging, and observability

- Incident response and postmortems

## Learning Outcomes

- Apply appropriate SDLC models to project contexts

- Elicit, specify, and validate software requirements

- Design software architectures using standard patterns

- Implement effective testing strategies

- Manage software evolution and technical debt

- Work effectively in agile development teams
