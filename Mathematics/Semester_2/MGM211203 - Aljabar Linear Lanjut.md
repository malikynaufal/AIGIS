# MGM211203 — Aljabar Linear Lanjut (Advanced Linear Algebra)

## Course Information

- **Course Code:** MGM211203

- **Course Name:** Aljabar Linear Lanjut (Advanced Linear Algebra)

- **Credit Hours (SKS):** 3

- **Semester:** 2

- **Prerequisites:** MGM211102 — Aljabar Linear

## Course Description
Deep dive into abstract vector spaces, spectral theory, and matrix decomposition methods. Students learn to work with abstract algebraic structures and apply advanced decomposition techniques including eigendecomposition, singular value decomposition (SVD), and Jordan canonical form.

## Key Topics

### Abstract Vector Spaces

- Vector spaces over arbitrary fields (R, C, F_p)

- Subspaces: sum, intersection, direct sum

- Quotient spaces and cosets

- Linear maps: kernel, image, isomorphism theorems

- Rank-nullity theorem (proof and applications)

- Dual spaces and bilinear forms

### Inner Product Spaces

- Inner products: real and complex

- Norms induced by inner products

- Cauchy-Schwarz inequality

- Orthogonal projections and best approximation

- Gram-Schmidt orthogonalization

- Orthonormal bases and Fourier coefficients

### Spectral Theory

- Eigenvalues and eigenvectors: geometric and algebraic multiplicity

- Minimal and characteristic polynomials

- Cayley-Hamilton Theorem

- Diagonalizable matrices

- Spectral Theorem for symmetric and Hermitian matrices

- Normal matrices

### Matrix Decompositions

- LU decomposition and Gaussian elimination revisited

- QR decomposition (Gram-Schmidt and Householder)

- Singular Value Decomposition (SVD)
  - Existence and uniqueness
  - Pseudoinverse (Moore-Penrose)
  - Applications: least squares, dimensionality reduction

- Cholesky decomposition for positive definite matrices

- Schur decomposition

- Jordan canonical form (overview)

### Bilinear and Quadratic Forms

- Bilinear forms and their matrix representations

- Symmetric and skew-symmetric bilinear forms

- Quadratic forms: Sylvester's criterion, inertia

- Positive definite and semidefinite matrices

- Applications in optimization and machine learning

### Applications

- Principal Component Analysis (PCA) foundations

- PageRank algorithm via power iteration

- Matrix norms and condition numbers

- Error analysis in numerical linear algebra

- Tensor products (introduction)

## Learning Outcomes

- Work with abstract vector spaces and linear maps over various fields

- Apply spectral theory to analyze matrix properties

- Compute and interpret matrix decompositions (LU, QR, SVD, Cholesky)

- Analyze bilinear and quadratic forms

- Relate linear algebra concepts to applications in data science and computing

- Prove theorems about linear algebraic structures
