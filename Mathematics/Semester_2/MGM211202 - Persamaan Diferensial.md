# MGM211202 — Persamaan Diferensial (Ordinary Differential Equations)

## Course Information

- **Course Code:** MGM211202

- **Course Name:** Persamaan Diferensial (Ordinary Differential Equations)

- **Credit Hours (SKS):** 3

- **Semester:** 2

- **Prerequisites:** MGM211201 — Kalkulus II

## Course Description
Study of ordinary differential equations (ODEs) and their applications to physical and engineering problems. Covers theoretical foundations and solution methods for first-order and second-order ODEs, both linear and nonlinear, including systems of ODEs.

## Key Topics

### First-Order Differential Equations

- Separable equations and separation of variables

- Exact differential equations and integrating factors

- Linear first-order equations: standard form and solution methods

- Bernoulli equations

- Homogeneous equations

- Substitutions: xy substitution, reduction of order

- Applications: population growth, mixing problems, terminal velocity

### Second-Order Linear Differential Equations

- Basic concepts: homogeneous vs. inhomogeneous, linear independence

- Homogeneous equations with constant coefficients

- Characteristic equation and solution methods

- Nonhomogeneous methods: undetermined coefficients

- Method of variation of parameters

- Cauchy-Euler (equidimensional) equations

- Power series solutions

- Systems of first-order linear equations: matrix methods

### Solution Methods and Theoretical Framework

- Existence and uniqueness theorems

- General theory of linear equations

- Wronskian and linear independence

- Fundamental matrix solution

- Applications to engineering and physics systems

- Phase plane analysis (qualitative methods)

### Partial Differential Equations Introduction

- Introduction to parabolic, elliptic, and hyperbolic PDEs

- Heat equation, wave equation, Laplace's equation

- Initial and boundary value problems

## Learning Outcomes

- Recognize ODE types and select appropriate solution methods

- Solve first and second order linear ODEs analytically

- Apply ODEs to model real-world physical processes

- Use matrix methods for systems of linear ODEs

- Analyze solution stability qualitatively

- Model engineering and physical problems using differential equations
