# MGM211205 — Struktur Data dan Algoritma (Data Structures and Algorithms)

## Course Information
- **Course Code:** MGM211205
- **Course Name:** Struktur Data dan Algoritma (Data Structures and Algorithms)
- **Credit Hours (SKS):** 3
- **Semester:** 2
- **Prerequisites:** MGM211105 — Pengantar Pemrograman

## Course Description
Study of fundamental data structures and algorithm analysis. Students learn to implement and analyze algorithms for sorting, searching, and computational problems. The course emphasizes algorithmic efficiency, complexity analysis, and problem-solving techniques essential for software development.

## Key Topics

### Fundamental Data Structures
- Abstract data types and data structure design principles
- Arrays and linked lists (singly, doubly, circular)
- Stacks and queues: operations and implementations
- Trees: binary trees, binary search trees, AVL trees
- Heaps: priority queues and heap sort
- Graphs: adjacency lists, adjacency matrices, traversals
- Hash tables: collision resolution, hash functions

### Sorting and Searching Algorithms
- Divide and conquer: merge sort, quick sort, heap sort
- Comparison-based lower bounds
- Searching: linear search, binary search, hashing
- External sorting: merge sort for large files
- Sorting networks

### Algorithm Analysis
- Asymptotic notation: O, Ω, Θ
- Worst-case, average-case, best-case analysis
- Recurrence relations and Master theorem
- Space-time complexity tradeoffs
- Amortized analysis (accounting, potential)

### Algorithm Design Techniques
- Greedy algorithms and their applications
- Dynamic programming: knapsack, coin change, longest common subsequence
- Backtracking and branch-and-bound
- Divide and conquer strategy
- Randomized algorithms: quick sort randomized, hashing

### Advanced Topics (Optional)
- Union-find data structure (disjoint sets)
- Suffix trees and string algorithms
- NP-completeness introduction
- Introduction to graph algorithms: Dijkstra, Bellman-Ford, Ford-Fulkerson

## Learning Outcomes
- Implement classic data structures using appropriate languages
- Analyze algorithm complexity and select efficient algorithms
- Apply dynamic programming and greedy techniques to optimization problems
- Understand tradeoffs between time and space complexity
- Debug and test data structures and algorithms
- Develop efficient software solutions for computational problems
