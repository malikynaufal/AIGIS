# MGM211206 — Pemrograman Lanjutan (Advanced Programming)

## Course Information

- **Course Code:** MGM211206

- **Course Name:** Pemrograman Lanjutan (Advanced Programming)

- **Credit Hours (SKS):** 3

- **Semester:** 2

- **Prerequisites:** MGM211105 — Pengantar Pemrograman

## Course Description
Intermediate to advanced programming concepts focusing on object-oriented programming (OOP), design principles, and software architecture patterns. Students deepen their coding skills through complex programming projects involving GUI development, networking, and multi-module applications.

## Key Topics

### Object-Oriented Programming

- OOP paradigms: encapsulation, inheritance, polymorphism, abstraction

- Classes and objects: constructors, destructors, member functions

- Inheritance: single, multiple (diamond problem), virtual inheritance

- Polymorphism: compile-time (overloads) and run-time (virtual methods)

- Abstract classes and interfaces

- Composition vs. inheritance tradeoffs

### SOLID Design Principles

- Single Responsibility Principle (SRP)

- Open-Closed Principle (OCP)

- Liskov Substitution Principle (LSP)

- Interface Segregation Principle (ISP)

- Dependency Inversion Principle (DIP)

- Practical applications and refactoring exercises

### Exception Handling and Clean Code

- Exception hierarchies and custom exceptions

- Try-with-resources / context managers

- Logging and debugging techniques

- Clean code concepts: meaningful names, functions, comments

- Code smells and refactoring patterns

- Unit testing with frameworks (JUnit, PyTest, NUnit)

### Software Design Patterns

- Creational: Singleton, Factory Method, Builder

- Structural: Adapter, Composite, Decorator, Proxy

- Behavioral: Observer, Strategy, Command, Template Method

- Model-View-Controller (MVC), Model-View-ViewModel (MVVM)

- Dependency Injection and Inversion of Control

### GUI Programming and Event Handling

- Event-driven programming paradigms

- GUI frameworks overview (Java Swing/JavaFX, Python Tkinter/PyQt)

- Layout managers and UI component composition

- Event listeners and callback mechanisms

- Basic 2D graphics and rendering

- Multithreaded UI applications

### Networking and Concurrency Basics

- Socket programming (TCP/UDP)

- HTTP clients and servers

- Concurrent and multithreaded programming

- Synchronization, deadlock, thread safety

- Async/await patterns (async/await in Python, CompletableFuture in Java)

## Learning Outcomes

- Design and implement OOP-based software solutions

- Apply SOLID principles and design patterns in code

- Write clean, maintainable, and testable code

- Develop GUI applications with event-driven architecture

- Implement basic network communication protocols

- Understand concurrency and synchronization concepts
