# Optimization

## Overview

Optimization is the mathematical discipline of finding the best solution from all feasible solutions. It underpins virtually all of engineering design, machine learning, operations research, and — critically for geodesy — parameter estimation, datum definition, and network design.

**Prerequisites**: [[Multivariable Calculus]], [[Linear Algebra]], [[Numerical Methods]]

## 1. Introduction

### 1.1 Problem Statement

$$\min_{\mathbf{x} \in \mathcal{X}} f(\mathbf{x})

$ $

where $ f: \mathbb{R}^n \to \mathbb{R} $ is the objective function, and $\mathcal{X} \subseteq \mathbb{R}^n $ is the feasible region.

### 1.2 Classification

| Category | Objective | Constraints |
|----------|-----------|-------------|
| Linear Programming (LP) | Linear | Linear |
| Quadratic Programming (QP) | Quadratic | Linear |
| Convex Programming | Convex | Convex |

## 2. Unconstrained Optimization

### 2.1 Necessary Conditions (1st Order)

If $\mathbf{x}^*$ is a local minimum of $  f $ (differentiable): $ $\nabla f(\mathbf{x}^*) = \mathbf{0} $$

$\mathbf{x}^*$ is called a **critical point**.

### 2.2 Sufficient Conditions (2nd Order)

The Hessian matrix $ H(\mathbf{x}^*) $ (matrix of second partial derivatives)

$ $ H_{ij} = \frac{\partial^2 f}{\partial x_i\partial x_j}$$

| Condition | Type |
|-----------|------|
| $ H $ positive definite (all eigenvalues $>0 $) | Strict local minimum |
| $ H $ negative definite (all eigenvalues $<0 $) | Strict local maximum |
| $ H $ has mixed signs | Saddle point |
| $ H $ singular (has zero eigenvalue) | Inconclusive |

### 2.3 Convexity $ f $ is **convex** if

$ $ f(\lambda\mathbf{x} + (1-\lambda)\mathbf{y}) \leq \lambda f(\mathbf{x}) + (1-\lambda)f(\mathbf{y}) \\quad \\forall \lambda \in [0,1]$$

**Key property**: Any local minimum is a global minimum.

**Test**: $ f $ is convex $\\iff $ $ H(\mathbf{x}) \\succeq 0 $ (positive semidefinite) for all $\mathbf{x} $.

## 3. Gradient Descent

### 3.1 Algorithm

$ $\mathbf{x}_{k+1} = \mathbf{x}_k - \alpha_k\nabla f(\mathbf{x}_k)

$$

where $\alpha_k > 0 $ is the step size (learning rate).

### 3.2 Step Size Selection

**Fixed step size**: $\alpha_k = \alpha $ constant.

**Backtracking line search**: Start with $\alpha = 1 $, while $ f(\mathbf{x}_k - \alpha\nabla f) > f(\mathbf{x}_k) - c\alpha\\|\nabla f\\|^2 $, reduce $\alpha $.

**Exact line search**: $\alpha_k = \arg\min_{\alpha>0}f(\mathbf{x}_k - \alpha\nabla f) $### 3.3 Convergence

For convex $ f $ with Lipschitz gradient ( $\\|\nabla f - \nabla g\\| \leq L\\|x-y\\| $):

$ $ f(\mathbf{x}_k) - f(\mathbf{x}^*) \leq \frac{L\\|\mathbf{x}_0 - \mathbf{x}^*\\|^2}{2(k+1)}$$

Convergence rate: $ O(1/k) $— sublinear.

### 3.4 Momentum

$ $\mathbf{v}_{k+1} = \beta\mathbf{v}_k + \alpha\nabla f(\mathbf{x}_k)\mathbf{x}_{k+1} = \mathbf{x}_k - \mathbf{v}_{k+1} $$

Accelerates convergence for ill-conditioned problems.$\beta \in [0.9, 0.999] $.

### 3.5 Newton's Method for Optimization

$ $\mathbf{x}_{k+1} = \mathbf{x}_k - [H(\mathbf{x}_k)]^{-1}\nabla f(\mathbf{x}_k)

$$

Quadratic convergence near minimum, but requires $ O(n^3) $ per step.

# ## 4.5 Worked Example

Find the point on $ x^2+y^2=4 $ closest to $ (3,0) $.

**Solution**: Minimize $ f(x,y) = (x-3)^2+y^2 $ subject to $ g(x,y)=x^2+y^2-4=0 $.

Lagrangian: $ L = (x-3)^2+y^2+\lambda(x^2+y^2-4) $

$\partial L/\partial x = 2(x-3)+2\lambda x = 0 \\implies x(1+\lambda) = 3 $
$\partial L/\partial y = 2y+2\lambda y = 0 \\implies y(1+\lambda)=0 $ From second: $ y=0 $ or $\lambda=-1 $.

If $ y=0 $: $ x^2=4 $, $ x=\pm 2 $. $ x(1+\lambda)=3 $ with $ x=2 $: $\lambda=1/2 $. ✓
$ f(2,0)=1 $, $ f(-2,0)=25 $. Closest point: $ (2,0) $, distance $= 1 $.

## 5. Karush-Kuhn-Tucker (KKT) Conditions

### 5.1 Standard Form

$ $\min f(\mathbf{x}) \\quad \text{subject to} \\quad g_i(\mathbf{x}) \leq 0, \\quad h_j(\mathbf{x}) =
0

$$

# ## 5.2 KKT Conditions $ $\nabla f + \sum_i\mu_i\nabla g_i + \sum_j\lambda_j\nabla h_j = \mathbf{0}\mu_i \geq 0, \\quad g_i(\mathbf{x}^*) \leq 0, \\quad \mu_i g_i(\mathbf{x}^*) = 0

$$

The last condition is **complementary slackness**: either $\mu_i=0 $ (constraint inactive) or $ g_i=0 $ (constraint active).

## 6. Convex Optimization

### 6.1 Linear Programming (LP
)

$ $\min \mathbf{c}^T\mathbf{x} \\quad \text{s.t.} \\quad A\mathbf{x} \leq \mathbf{b}, \\quad \mathbf{x} \geq \mathbf{0} $$

**Simplex method**: Moves along vertices of polytope.

**Interior-point methods**: $ O(n^{3.5}L) $ where $  L $ = bits of input.

### 6.2 Quadratic Programming (QP
)

$ $\min \frac{1}{2}\mathbf{x}^TQ\mathbf{x} + \mathbf{c}^T\mathbf{x} \\quad \text{s.t.} \\quad A\mathbf{x} \leq \mathbf{b} $$

Used in: least squares, portfolio optimization, SVM.

### 6.3 Conic Optimization

- **SOCP**: Second-order cone programming

- **SDP**: Semidefinite programming

- **Explore**: Exponential cone programming

### 6.4 Duality

**Lagrangian dual**:

$ $

d^*(\lambda, \mu) = \min_{\mathbf{x}} L(\mathbf{x},\lambda,\mu)d^* \leq p^*$$

(weak duality)

For convex problems: $ d^* = p^*$ (strong duality).

## 9. Practice Problems

### Problem 1
Minimize $ f(x,y)=x^2+y^2 $ subject to $ x+y=1 $.

**Solution**: Lagrangian $ L=x^2+y^2+\lambda(x+y-1) $
$\nabla L = (2x+\lambda, 2y+\lambda)=0 $, $ x+y=1 $
$ 2x=2y $→$ x=y=1/2 $, $\lambda=-1 $, $ f=1/2 $.

### Problem 2
Apply 3 iterations of gradient descent to $ f(x)=x^2 $ starting at $ x=1 $, $\alpha=0.5 $.

$ x_1 = 1-0.5(2) = 0 $
$ f(0) = 0 $→ already at minimum!

### Problem 3
Is $ f(x,y)=x^3+y^3-3xy $ convex on $\mathbb{R}^2 $?

$ H = \begin{bmatrix}6x & -3\\ -3&6y\end{bmatrix} $. At $ (1,1) $: eigenvalues $= 6\pm 3 > 0 $ (definite). But at $ (0,0) $: $  H = -3I$ (negative definite). NOT convex.
