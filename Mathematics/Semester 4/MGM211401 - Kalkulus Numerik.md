# MGM211401 — Kalkulus Numerik (Numerical Calculus)

## Course Information

- **Course Code:** MGM211401

- **Course Name:** Kalkulus Numerik (Numerical Calculus)

- **Credit Hours (SKS):** 3

- **Semester:** 4

- **Prerequisites:** MGM211201 — Kalkulus II; MGM211105 — Pengantar Pemrograman

## Course Description
Introduction to numerical methods for solving mathematical problems analytically intractable or unsolvable. Emphasizes error analysis, approximation theory, and implementation of algorithms using Python/MATLAB.

## Key Topics

### Foundations of Numerical Computation

- Sources of error: truncation, roundoff, catastrophic cancellation

- Floating-point arithmetic and IEEE 754

- Significant digits and relative/absolute error

- Condition number and numerical stability

- Machine epsilon and computational precision

- Error propagation in numerical calculations

### Numerical Differentiation

- Finite difference approximations: forward, backward, central

- Error analysis of finite differences

- Higher-order derivatives using finite differences

- Richardson extrapolation

- Numerical differentiation of multivariate functions

### Numerical Integration

- Composite Trapezoidal Rule

- Composite Simpson's 1/3 and 3/8 Rules

- Romberg integration (Richardson extrapolation)

- Gaussian quadrature: Gauss-Legendre

- Adaptive quadrature methods

- Error estimates and convergence order

- Multidimensional numerical integration

### Solving Nonlinear Equations

- Bisection method: bracketing and guaranteed convergence

- Newton-Raphson method: convergence and pitfalls

- Secant method and false position (regula falsi)

- Fixed-point iteration

- Muller's method

- Comparison of convergence rates (linear vs. superlinear)

### Interpolation and Approximation

- Polynomial interpolation: Lagrange and Newton forms

- Runge phenomenon and equidistant interpolation nodes

- Spline interpolation: cubic splines

- Least-squares fitting: polynomial and non-polynomial

- Chebyshev nodes and minimax approximation

- Trigonometric interpolation and DFT introduction

### Numerical Solution of ODEs

- Euler's method (forward and backward)

- Runge-Kutta methods (2nd and 4th order)

- Multi-step methods: Adams-Bashforth, Adams-Moulton

- Stability analysis of numerical methods

- Stiff equations and implicit methods

- Comparison of methods and step-size selection

## Learning Outcomes

- Analyze sources and propagation of numerical error

- Implement numerical differentiation and integration algorithms

- Solve nonlinear equations using iterative methods

- Construct polynomial interpolants and spline approximations

- Implement ODE solvers and analyze convergence

- Select appropriate numerical methods based on problem requirements
