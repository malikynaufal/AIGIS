# Semester 4 — Aljabar Abstrak (Expanded)

## Course Overview

Abstract algebra studies algebraic structures: groups, rings, and fields. It provides the theoretical foundation for coding theory, cryptography, and advanced geometry.

---

## Syllabus

### Unit 1: Groups

- **Definition**: Set $G$with binary operation$*$satisfying closure, associativity, identity, and inverses.

- **Examples**:$(\\mathbb{Z},+)$, $(\\mathbb{R}^\\times,\\times)$, $S_n$(permutations),$GL(n,\\mathbb{R})$(invertible matrices)

- **Subgroups**:$H \\subseteq G$closed under same operation,$\\{0\\}$and$G$are trivial subgroups

- **Cosets and Lagrange's theorem**:$|H|$divides$|G|$for finite$G$- **Normal subgroups and quotient groups**:$G/H$quotient group exists when$H$is normal

- **Homomorphisms**:$\\phi(ab) = \\phi(a)\\phi(b)$, kernel is normal subgroup

- **Isomorphism theorems**: First, Second, Third isomorphisms

### Unit 2: Rings

- **Definition**: Set $R$with addition$+$and multiplication$\\cdot$satisfying ring axioms.

- **Examples**:$\\mathbb{Z}$, $\\mathbb{Z}_n$, $M_n(\\mathbb{R})$(square matrices)

- **Integral domains**:$ab=0$→$a=0$or$b=0$- **Fields**: Every nonzero element is a unit. Example:$\\mathbb{Q}, \\mathbb{R}, \\mathbb{C}, \\mathbb{Z}_p$for prime$p$.

- **Ideals and quotient rings**: $R/I$quotient ring exists for ideal$I$- **Polynomial rings**:$\\mathbb{R}[x]$, factorization, irreducibility

### Unit 3: Fields

- **Field extensions**: $\\mathbb{Q}(\\sqrt{2})$extends$\\mathbb{Q}$- **Galois theory**: Connection between field extensions and groups

---

## Key Theorems

- **Lagrange's Theorem**: In finite group$G$, $|H|$divides$|G|$- **First Isomorphism Theorem**:$G/\\ker(\\phi) \\cong \\text{Im}(\\phi)$

- **Cayley's Theorem**: Every group is isomorphic to a permutation group

## Geodesy Applications

- **Coding theory (groups)**: Error detection in satellite transmissions

- **Finite fields**: Number theory in coordinate systems

- **Symmetry groups**: Crystal structures, spherical harmonics
