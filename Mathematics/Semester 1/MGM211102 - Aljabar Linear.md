# MGM211102 — Aljabar Linear (Linear Algebra)

## Course Information

- **Course Code:** MGM211102

- **Course Name:** Aljabar Linear (Linear Algebra)

- **Credit Hours (SKS):** 4

- **Semester:** 1

- **Prerequisites:** SMA-level Mathematics

## Course Description
Systematic study of vector spaces, matrices, linear transformations, and systems of linear equations. This course develops both computational skills and abstract reasoning about linear structures, providing essential tools for computer science, data science, and applied mathematics.

## Key Topics

### Systems of Linear Equations

- Gaussian elimination and row echelon form

- Row reduction algorithm

- Existence and uniqueness of solutions

- Homogeneous systems and free variables

- Applications to network flow and balancing chemical equations

### Vectors and Vector Spaces

- Vectors in R^n: algebraic and geometric interpretations

- Linear combinations and span

- Linear independence and dependence

- Vector spaces and subspaces (null space, column space, row space)

- Basis and dimension

- Rank-Nullity Theorem

### Matrices and Linear Transformations

- Matrix algebra: addition, scalar multiplication, matrix multiplication

- Inverse of a matrix and elementary matrices

- Determinants: cofactor expansion, properties, geometric interpretation

- Linear transformations: definition, kernel, image

- Matrix representations of linear transformations

- Coordinate change and change of basis

### Orthogonality

- Dot product, length, and distance in R^n

- Orthogonal and orthonormal sets

- Orthogonal projections and Gram-Schmidt process

- Orthogonal matrices

- Least-squares approximation and applications

### Eigenvalues and Eigenvectors

- Definitions and characteristic equation

- Diagonalization of matrices

- Applications to dynamical systems and Markov chains

- Symmetric matrices and orthogonal diagonalization

## Learning Outcomes

- Solve systems of linear equations using matrix methods

- Determine linear independence, span, and dimension of vector spaces

- Compute determinants and apply Cramer's rule

- Apply matrix operations to solve practical problems

- Use Gram-Schmidt process for orthogonalization

- Compute eigenvalues and eigenvectors; diagonalize matrices
