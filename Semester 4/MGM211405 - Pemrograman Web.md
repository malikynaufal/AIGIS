# MGM211405 — Pemrograman Web (Web Programming)

## Course Information
- **Course Code:** MGM211405
- **Course Name:** Pemrograman Web (Web Programming)
- **Credit Hours (SKS):** 3
- **Semester:** 4
- **Prerequisites:** MGM211105 — Pengantar Pemrograman

## Course Description
Comprehensive introduction to modern web development technologies. Students learn to build interactive, responsive web applications using HTML, CSS, JavaScript, and server-side frameworks with databases integration.

## Key Topics

### HTML5 Fundamentals
- Document structure: DOCTYPE, head, body elements
- Semantic HTML: header, nav, main, section, article, footer
- Forms and input types: validation, accessibility
- Tables, lists, and embedded media
- Metadata and SEO considerations
- HTML5 Canvas API introduction

### CSS3 and Responsive Design
- Selectors: class, ID, attribute, pseudo-classes, pseudo-elements
- Box model, positioning, and display properties
- Flexbox layout model
- CSS Grid layout
- Media queries and responsive design principles
- Animations, transitions, and transforms
- CSS preprocessors (SASS/SCSS introduction)

### JavaScript Fundamentals
- Variables, scoping, and closures
- DOM manipulation and event handling
- Asynchronous programming: callbacks, Promises, async/await
- Fetch API for HTTP requests
- ES6+ features: modules, template literals, destructuring, arrow functions
- JSON handling and data binding
- LocalStorage and sessionStorage
- Canvas drawing and SVG manipulation

### Server-Side Development
- Client-server architecture
- Node.js and Express.js framework
- REST API design and implementation
- Middleware patterns
- Template engines (EJS, Pug)
- Session management and cookies
- Authentication: JWT (JSON Web Tokens)

### Databases and ORM
- MongoDB: NoSQL fundamentals, document model
- SQL databases: MySQL/PostgreSQL with Node.js
- Object-Relational Mapping (ORM): Sequelize, Mongoose
- CRUD operations through API endpoints
- Data validation and sanitization
- Database security: SQL injection prevention

### Deployment and Modern Tools
- Git for version control
- Deployment: Netlify, Vercel, Heroku
- Package managers: npm, yarn
- Build tools and bundlers (introduction to Vite/Webpack)
- Testing: unit testing, integration testing
- Web security: CORS, CSP, XSS prevention
- Progressive Web Apps (PWA) concepts

## Learning Outcomes
- Build semantic HTML documents following web standards
- Create responsive layouts using Flexbox and CSS Grid
- Write interactive JavaScript applications with async capabilities
- Develop RESTful APIs using Node.js and Express
- Connect web applications to databases securely
- Deploy web applications to cloud platforms
