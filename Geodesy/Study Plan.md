# Geodesy Study Plan - UGM Kurikulum 2021

## Overview
This study plan is designed to help you navigate the Geodesy Engineering curriculum at Universitas Gadjah Mada (UGM) efficiently. It leverages your Obsidian vault structure to organize course materials, notes, and [[Resources]].

## How to Use This Vault
1. **Semester Folders**: Each semester (Semester 1 through Semester 8) contains:
   - A `README.md` with semester overview and course list
   - Individual course notes files (named `KODE - Nama Mata Kuliah.md`)
   - Use these files to take lecture notes, summarize concepts, and store assignments

2. **Electives Folder**: The `Pilihan` folder contains all elective courses. Choose based on your interests and career goals.

3. **Concepts Folder**: Contains detailed notes on fundamental geodesic concepts (datums, projections, etc.) that span multiple courses.

4. **Resources Folder**: Store textbooks, lecture slides, and external references here.

5. **Sources Folder**: Contains raw curriculum documents and reference materials.

## Study Strategy

### Semester-by-Semester Focus

- **Semester 1-2**: Focus on foundational mathematics and physics (Kalkulus, Aljabar Linear, Fisika Dasar, Statistika Dasar) and introductory geodesy concepts (Pengantar Ilmu Kebumian, Sistem Koordinat).

- **Semester 3-4**: Build core geodesy skills (Geometri Diferensial, Sistem Referensi Geodesi, Geodesi Satelit, Proyeksi Peta) and practical skills (Pemrograman Komputer, Sistem Basisdata, Kartografi).

- **Semester 5-6**: Advance to specialized geodesy topics (Geodesi Fisis, Survei GNSS, Survei Hidrografi, Analisis Citra Penginderaan Jauh) and research methods.

- **Semester 7-8**: Focus on professional practice (Kerja Praktik, Proyek Rekayasa) and thesis work (Skripsi), complemented by electives.

### Weekly Routine
1. **Lecture Attendance**: Take notes directly in the respective course file.
2. **Weekly Review**: Spend 30 minutes each Sunday reviewing notes from the week and linking related concepts.
3. **Monthly Synthesis**: At the end of each month, create a summary note in the Concepts folder linking ideas across courses.
4. **Exam Preparation**: 
   - Two weeks before exams: Review notes and create flashcards for key concepts.
   - One week before: Do practice problems and past exams.

### Active Learning Techniques

- **Feynman Technique**: After learning a concept, explain it in simple terms as if teaching a beginner.

- **Spaced Repetition**: Review notes at increasing intervals (1 day, 3 days, 7 days, 15 days).

- **Interleaving**: Mix study of different but related topics (e.g., study coordinate systems alongside map projections).

- **Dual Coding**: Combine verbal explanations with diagrams (especially important for geodesy).

## Resources to Supplement UGM Curriculum

### Core Textbooks

- "Elementary Surveying" by Charles D. Ghilani (for surveying fundamentals)

- "Adjustment Computations" by Charles D. Ghilani (for least squares)

- "GPS Satellite Surveying" by Alfred Leick (for GNSS)

- "Remote Sensing and Image Interpretation" by Lillesand, Kiefer, and Chipman (for remote sensing)

### Online Courses

- Coursera: "Geospatial Analysis" by University of California Davis

- edX: "Geographic Information Systems" by University of Toronto

- YouTube: Kelkrit Jaya Geodesy channel (Indonesian language explanations)

### Software Tools

- **QGIS** (free): For GIS and cartography practice

- **GNSS-SDR** (free): For GNSS signal processing

- **GMT** (free): For processing geodetic data

- **Python** (with NumPy, SciPy, Matplotlib): For numerical analysis and visualization
