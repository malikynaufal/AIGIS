## 2. Elective Descriptions

### TKD213618 — GNSS Terapan

**Advanced GNSS applications for surveying and navigation.**

| Topic | Description |
|-------|-------------|
| Multi-frequency processing | L1/L2/L5 combinations |
| RTK/PPK workflows | Real-time & post-processed kinematic |
| Network RTK | CORS/VRS systems |
| GNSS meteorology | PWV estimation |
| Quality assurance | Integrity monitoring |

**Links:** [[GNSS]], [[RTK]], [[PPP]], [[Least Squares Adjustment]]

### TKD213623 — Survei Deformasi

**Monitoring structural and crustal deformation.**

| Topic | Description |
|-------|-------------|
| Deformation models | Linear, nonlinear, time series |
| Measurement techniques | GNSS, total station, InSAR |
| Analysis methods | Filtering, hypothesis testing |
| Alarm systems | Threshold-based alerts |
| Case studies | Dam, bridge, landslide monitoring |

**Links:** [[Crustal Deformation]], [[Least Squares Adjustment]], [[Statistical Testing]]

### TKD214706 — Mitigasi dan Manajemen Bencana

**Disaster risk reduction using geospatial technologies.**

| Topic | Description |
|-------|-------------|
| Hazard mapping | Flood, landslide, earthquake |
| Risk assessment | Vulnerability × Exposure |
| Early warning systems | Sensor networks, models |
| Post-disaster mapping | Damage assessment |

**Links:** [[Crustal Deformation]], [[Remote Sensing]], [[Geospatial Analysis]]

### TKD214716 — SIG Berbasis Web

**Web GIS development for geospatial applications.**

| Technology | Use |
|------------|-----|
| Leaflet/OpenLayers | Client-side mapping |
| GeoServer | WMS/WFS services |
| PostGIS | Spatial database |
| Django/Flask + React | Full-stack apps |

**Links:** [[Sistem Informasi Geografis]], [[Spatial Databases]]
