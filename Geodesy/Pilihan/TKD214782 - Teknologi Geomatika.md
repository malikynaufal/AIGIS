## Deskripsi Mata Kuliah

Teknologi Geomatika adalah mata kuliah pilihan yang membahas integrasi teknologi mutakhir dalam geomatika, termasuk sistem UAV/drone, mobile mapping, LiDAR, fotogrametri digital, dan augmented reality (AR) untuk aplikasi geospasial. Geomatika merupakan disiplin ilmu modern yang menggabungkan survei, pemetaan, penginderaan jauh, SIG, GNSS, dan teknologi informasi untuk pengelolaan data geospasial secara end-to-end.

Mata kuliah ini dirancang untuk membekali mahasiswa dengan pemahaman tentang teknologi terkini yang digunakan dalam industri geospasial. Mahasiswa akan mempelajari drone mapping menggunakan UAV, mobile mapping system (MMS) untuk pemetaan jalan, pemrosesan point cloud LiDAR, fotogrametri digital dengan Structure-from-Motion (SfM), dan aplikasi AR untuk visualisasi data geospasial.

Pembelajasan dilakukan secara interaktif melalui demonstrasi teknologi di laboratorium dan proyek kelompok. Mahasiswa akan mengoperasikan drone sederhana, memproses data point cloud menjadi model 3D, dan membuat aplikasi visualisasi augmented reality sederhana. Lab geomatika UGM menyediakan akses ke drone (DJI Phantom/Mavic), total station robotic, dan perangkat lunak pemrosesan LiDAR.

## Topik Utama

### 1. Teknologi Drone dan UAV

- Jenis dan platform UAV

- Perencanaan misi survei drone

- Pemrosesan data drone (orthophoto, DTM)

### 2. LiDAR dan Point Cloud

- Prinsip LiDAR dan jenis sistem

- Pemrosesan point cloud

- Ekstraksi fitur dari point cloud

### 3. Fotogrametri Digital

- Struktur dari gerak (Structure-from-Motion)

- Digital terrain model dari foto

- Integrasi LiDAR dan fotogrametri

### 4. Teknologi Visualisasi

- Augmented Reality (AR) untuk data geospasial

- Visualisasi 3D dan Virtual Reality (VR)

## Tujuan Pembelajaran

1. Menguasai teknologi drone untuk survei dan pemetaan
2. Memproses data LiDAR dan point cloud
3. Menerapkan fotogrametri digital untuk model 3D
4. Menggunakan AR/VR untuk visualisasi geospasial
