# 📗 Semester 6 — Geodetic Networks, Hydrography & Geospatial Analysis

**SKS:** 20 (Compulsory)  
**Focus:** Design and adjustment of geodetic networks, advanced hydrography, spatial analysis, and preparation for the capstone project.

## 📚 Course List & Descriptions

| Code | Course | SKS | Focus |
|------|--------|-----|-------|
| TKD213601 | **Metodologi Penelitian** (Research Methodology) | 3 | Scientific method, hypothesis, statistical analysis |
| TKD213602 | **Perancangan Sistem Informasi Pertanahan** (Land Information System Design) | 3 | UML, database design, web GIS for land administration |
| TKD213603 | **Penetapan dan Penegasan Batas Wilayah** (Boundary Demarcation) | 3 | Legal framework, field procedure, GNSS/UAV technology |
| TKD213604 | **Jaring Kontrol Geodesi** (Geodetic Control Networks) | 3 | Network design, optimization, monumentation, SKRGI |
| TKD213605 | **Survei Hidrografi II** (Advanced Hydrography) | 3 | Multibeam sonar, side-scan, tidal analysis, chart datum |
| TKD213606 | Analisis Citra Penginderaan Jauh (Remote Sensing Image Analysis) | 3 | Classification, change detection, accuracy assessment |
| TKD213607 | Praktikum Analisis Citra Penginderaan Jauh (Lab) | 1 | ENVI/QGIS/SNAP workflow |
| TKD213608 | **Analisis Geospasial** (Geospatial Analysis) | 3 | Overlay, buffer, network analysis, spatial statistics |
| TKD213609 | Praktikum Analisis Geospasial (Lab) | 1 | GIS laboratory exercises |

## 🧭 Learning Outcomes

By the end of this semester, you should be able to:
1. Design a geodetic control network with appropriate accuracy
2. Conduct advanced hydrographic surveys using multibeam systems
3. Perform spatial analysis using GIS tools (overlay, buffer, network)
4. Classify satellite imagery and assess accuracy
5. Write a research proposal following scientific methodology
6. Understand land boundary demarcation procedures
