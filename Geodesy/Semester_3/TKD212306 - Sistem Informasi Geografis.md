## Deskripsi Mata Kuliah

Sistem Informasi Geografis (SIG) adalah ilmu yang mempelajari tentang sistem basisdata untuk menyimpan dan menganalisis data geospasial, didukung oleh teknologi informasi berbasis komputer modern. SIG digunakan untuk melakukan penyimpanan, pengambilan, dan pengolahan data yang bersifat geografis, baik vektor maupun raster. SIG semakin berkembang, dengan munculnya teknologi cloud dan membludaknya data. Geodesi modern menggunakan SIG baik pada tingkat aslinya menggunakan basisdata maupun vektor maupun menggunakan aplikasi GIS berbasis web berbasis komputasi awan.

Guna mendukung misi dan visi program studi Teknik Geodesi UGM, mata kuliah ini memperkenalkan konsep, teknik, dan aplikasi SIG bagi para mahasiswa. Peran SIG dalam survei dan pemetaan merupakan mata kuliah wajib bagi mahasiswa teknik geodesi karena diperolehnya landasan SIG yang solid mampu melakukan penyimpanan basisdata geospasial terpadu untuk mendukung berbagai kebutuhan pekerjaan survei selanjutnya (geodesi). Informasi geospasial menjadi kebutuhan penting dalam berbagai bidang fungsional, seperti penentuan posisi dan navigasi, pemetaan, pertahanan dan keamanan negara, pengelolaan sumber daya alam, perencanaan wilayah, pertanian, kehutanan, pengelolaan bencana, dan pengawasan sumber daya energi bumi.

Mata kuliah ini mencakup konsep dan prinsip SIG, struktur data vektor dan raster, manipulasi data berbasis pemrograman, analisis spasial, desain database geospasial, pengukuran titik mengikuti prinsip GIS, prinsip klerikalisasi lahan, dan manajemen proyek SIG. Mahasiswa juga akan belajar melakukan pemodelan sistem untuk menjawab kebutuhan data spasial baik pada tingkat raw (lay level), tersembunyi (hidden level), maupun konflik (conflict level). Mata kuliah ini mengedepankan aplikasi komputasi modern dalam SIG untuk memenuhi kebutuhan masalah di lapangan dengan prasyarat mata kuliah basisdata relasional.

## Topik Utama

### 1. Konsep dan Prinsip Dasar

- Model data geospasial dan struktur basisdata

- Organisasi data geospasial: basisdata tingkat mentah dan tersembunyi

- Perancangan basisdata, basisdata relasional, Normalisasi hingga Norma 5, basisdata grafik

- Merancang dan mengimplementasi sistem basisdata SIG

- Representasi bangun ruang dalam SIG

### 2. Manipulasi dan Analisis Data

- Mengimpor dan mengekspor format data SIG

- Mengerjakan, menganalisis, dan memvisualisasikan data geospasial

- Kuis dan definisi geometris dalam SIG, SQL umum, dan interpretasi lingkaran wilayah dan geoelement

### 3. Aplikasi Praktis

- Menggunakan dan mengoperasikan teknologi SIG berbasis cloud untuk data geospasial

- Melakukan analisis spasial untuk mendukung pengambilan keputusan

## Tujuan Pembelajaran

1. Menguasai konsep dan prinsip SIG
2. Melakukan manipulasi dan analisis data geospasial
3. Mengimplementasi sistem basisdata SIG
4. Menerapkan pengetahuan SIG untuk mendukung masalah geodesi dan bidang terkait
