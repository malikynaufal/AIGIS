## Deskripsi Mata Kuliah

Analisis Statistika adalah mata kuliah lanjutan dari Statistika Dasar yang mempelajari metode-metode statistik multivariat dan analisis data kompleks untuk geodesi dan survei. Mata kuliah ini mencakup analisis regresi berganda, analisis varians (ANOVA) lanjutan, analisis faktor, analisis komponen utama (PCA), analisis cluster, analisis diskriminan, serta uji hipotesis untuk data multivariat. Metode statistik ini sangat penting untuk analisis kualitas data survei, pemodelan deformasi, dan pengambilan keputusan berbasis data.

Bagi mahasiswa Teknik Geodesi, analisis statistika lanjutan menjadi alat penting untuk menginterpretasikan hasil pengukuran yang kompleks. Analisis regresi digunakan untuk memodelkan hubungan antara parameter survei, PCA digunakan untuk reduksi dimensi data jaringan kontrol, analisis cluster membantu dalam klasifikasi titik kontrol, dan uji hipotesis multivariat digunakan untuk deteksi perubahan deformasi yang signifikan.

Pembelajaran dilakukan melalui kombinasi teori dan aplikasi praktis menggunakan perangkat lunak statistik seperti R, Python (scikit-learn, statsmodels), atau SPSS. Mahasiswa akan mengerjakan studi kasus nyata dari data survei geodesi, seperti analisis jaringan GNSS, pemodelan deformasi bendungan, atau klasifikasi lahan dari data penginderaan jauh.
