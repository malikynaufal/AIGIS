## Deskripsi Mata Kuliah

Praktikum Pemrograman Komputer adalah praktikum pendamping mata kuliah Pemrograman Komputer. Mahasiswa akan mempraktikkan konsep-konsep pemrograman yang dipelajari di kelas melalui latihan coding langsung di laboratorium komputer. Praktikum ini dirancang untuk membangun keterampilan coding hands-on yang diperlukan untuk pengolahan data geodesi dan pengembangan aplikasi geospasial.

Setiap sesi praktikum fokus pada topik tertentu yang selaras dengan materi kuliah teori. Mahasiswa akan mulai dari program "Hello World" sederhana, melanjutkan ke manipulasi array dan list untuk data koordinat, pembacaan/penulisan file data survei, hingga pembuatan kelas untuk merepresentasikan objek survei seperti titik kontrol, baseline GNSS, atau jaringan traversa.

Tugas akhir praktikum biasanya berupa proyek mini yang mengintegrasikan beberapa konsep, misalnya program untuk membaca file data mentah total station, melakukan reduksi koordinat, dan mengekspor hasil ke format standar industri (CSV, DXF, atau LandXML). Evaluasi didasarkan pada kebenaran logika, efisiensi kode, dan dokumentasi program.

## Topik Utama

### 1. Latihan Dasar Python/C++

- Variabel, tipe data, I/O dasar

- Loop dan kondisional untuk proses data

- Fungsi untuk kalkulasi survei

### 2. Manipulasi Data Survei

- Parsing file data mentah (RAW, GSI, CSV)

- Operasi array/matriks untuk koordinat

- Validasi dan pembersihan data

### 3. Proyek Integrasi

- Desain kelas untuk entitas survei

- Modul transformasi koordinat

- Ekspor hasil ke format standar

## Tujuan Pembelajaran

1. Mampu menulis, menguji, dan mendeprogram program untuk geodesi
2. Memproses data survei mentah menjadi informasi bermakna
3. Mengembangkan modul program yang reusable untuk tugas survei
4. Mendokumentasikan kode sesuai standar industri
