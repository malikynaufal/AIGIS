## Deskripsi Mata Kuliah

Sistem Basisdata adalah mata kuliah yang mempelajari konsep dasar dan prinsip-prinsip sistem basisdata relasional untuk penyimpanan dan pengaksesan data. Mata kuliah ini memberikan pengetahuan tentang bahasa basisdata, model data, normalisasi, dan pengambilan dan pemrosesan data. Konsep-konsep ini akan menjadi dasar bagi mahasiswa untuk memanfaatkan basisdata relasional dalam penyimpanan data geospasial untuk mendukung profesi di bidang geodesi dan geomatika.

Teknologi basisdata telah digunakan dalam bidang geodesi sejak berbagai proyek survei berdasarkan sistem koordinat yang diperlukan untuk mengumpulkan, menyimpan, dan memanipulasi data pengukuran teknis dan data pemetaan bersama. Basisdata relasional sangat cocok menyimpan data teknik geodesi yang memerlukan validasi dan pemeriksaan integritas data otomatis saat melakukan pengumpulan data secara berulang dan real-time. Mahasiswa yang mempelajari konsep basisdata, model data, bahasa basisdata, dan kontrol integritas data untuk mendukung industri geodesi dan geomatika akan memiliki keunggulan saat memasuki dunia kerja.

Mata kuliah ini memadukan teori dengan praktik langsung menggunakan perangkat lunak basisdata. Mahasiswa akan belajar membuat database, membangun skema, mengintegrasikan data pengukuran ke dalam basisdata, serta melakukan kueri dan analisis data menggunakan bahasa SQL. Konsep-konsep ini akan dikembangkan lebih lanjut di mata kuliah Praktikum Basisdata dan Sistem Informasi Geografis pada semester yang akan datang.

## Topik Utama

### 1. Dasar-Dasar Basisdata

- Konsep basisdata, skema, dan instansi

- Bahasa basisdata, model data, normalisasi

- Integritas referensial dan otentikasi

### 2. Bahasa dan Alasan SQL

- Bahasa data berdasarkan model relasional

- Bahasa Data Terintegrasi, ekslusif, dinamis (IDEF) dan basisdata terpisah

- Bahasa pemrograman berorientasi objek untuk memperumum basisdata

### 3. Penyimpanan Data Geospatial

- Model data vektor dan raster

- Interaksi data vektor dan raster

- Aplikasi spesifik

## Tujuan Pembelajaran

1. Memahami konsep dan prinsip-prinsip dasar basisdata
2. Melakukan proses perancangan basisdata untuk mengelola data geospasial
3. Mengimplementasikan basisdata dan melakukan kueri data menggunakan SQL untuk berbagai kebutuhan teknis
4. Menerapkan model data vektor dan raster dan mengintegrasikannya
