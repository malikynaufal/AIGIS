## Deskripsi Mata Kuliah

Pemrograman Komputer adalah mata kuliah fundamental yang mengajarkan konsep-konsep dasar pemrograman, algoritma, struktur data, dan pembangunan perangkat lunak. Mata kuliah ini menggunakan bahasa pemrograman Python atau C/C++ sebagai alat utama. Mahasiswa akan belajar logika pemrograman, variabel, kontrol alur, fungsi, struktur data dasar, dan pemrograman berorientasi objek.

Dalam konteks Teknik Geodesi, pemrograman menjadi kraman komputer adalah keterampilan wajib untuk pengolahan data pengukuran, otomasi tugas survei, pengembangan alat bantu survei, dan integrasi sistem geospasial. Banyak perangkat lunak survei modern dan sistem GNSS menyediakan API yang memerlukan keterampilan pemrograman untuk otomatisasi dan kustomisasi. Mahasiswa yang menguasai pemrograman akan memiliki keunggulan dalam dunia kerja geomatika modern.

Mata kuliah ini dipadukan dengan Praktikum Pemrograman Komputer (TKD211208) di mana mahasiswa menerapkan konsep-konsep teori secara langsung. Proyek akhir biasanya melibatkan pembuatan program sederhana untuk pengolahan data survei, seperti program hitung koordinat, transformasi koordinat, atau konversi data.

## Topik Utama

### 1. Dasar-Dasar Pemrograman

- Variabel, tipe data, dan operator

- Struktur kontrol: percabangan dan perulangan

- Fungsi dan modularisasi kode

### 2. Struktur Data Dasar

- Array, list, stack, queue

- Dictionary dan set

- File I/O dan serialisasi data

### 3. Pemrograman Berorientasi Objek

- Kelas dan objek

- Inheritance dan polymorphism

- Exception handling

## Tujuan Pembelajaran

1. Menguasai konsep dasar pemrograman dan algoritma
2. Mampu menulis program untuk memecahkan masalah geodesi sederhana
3. Memahami struktur data dan memilih yang tepat untuk data survei
4. Menerapkan pemrograman berorientasi objek dalam proyek geomatika
