# 🎓 Kurikulum Overview — Teknik Geodesi (8 Semester)

A linked roadmap built from [[Kurikulum Teknik Geodesi]]. Each semester below connects to the **concepts** you'll meet, so you can jump from "what to study" to "the theory."

## The arc
1. **Sem 1–2** — Math, physics, programming foundations. → [[Geodesy MOC]]
2. **Sem 3** — Enter the core: [[Reference Ellipsoid]], [[Datum]], [[Map Projection]], [[SIG]].
3. **Sem 4** — [[UTM]]/[[Transverse Mercator]], [[Vincenty Formula]], [[GNSS]] begins, [[Least Squares Adjustment]] seeds.
4. **Sem 5** — Remote sensing, photogrammetry, advanced SIG, [[Least Squares Adjustment]] proper, kadaster.
5. **Sem 6** — WebGIS, [[Gravity Field]]/[[Geoid]] (physical geodesy), hidrografi, Python geospatial.
6. **Sem 7** — Industry: deformation/GNSS tectonics, AI geospatial, precision adjustment, cartography.
7. **Sem 8** — Skripsi / specialization.

## Career profiles
Surveyor · Hidrografer · SIG Analyst · Remote Sensing Analyst · Cadastral Specialist · GNSS Engineer · WebGIS Dev · Peneliti Geospasial.
