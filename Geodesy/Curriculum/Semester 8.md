# Semester 8 — Thesis & Graduation

## Overview

Semester 8 is the final academic milestone. Students complete their *Kuliah Kerja Nyata* (KKN — community service project with geospatial application) and write their *Skripsi* (thesis). The thesis demonstrates independent research capability and is the primary graduation requirement.

## Courses (3 mata kuliah, total ~12 SKS)

| Code | Course | SKS | Type |
|------|--------|-----|------|
| TKD4802 | Skripsi | 6 | Thesis |
| UNV4801 | Kuliah Kerja Nyata (KKN) | 4 | Field |
| Elective (choose 1–2 from Pilihan) | 3–4 | Pilihan | |

## Thesis Requirements

A Geodesy thesis must demonstrate:

1. **Independent research ability** — original or applied research question
2. **Methodological rigor** — proper [[Least Squares Adjustment]], statistical validation
3. **Practical relevance** — real-world geodetic/geospatial application
4. **Written quality** — academic writing in Indonesian and English abstract
5. **Presentation** — seminar defense before faculty panel

### Thesis Topics (Recent Examples)
- GNSS-based geoid undulation for Indonesian regions
- Building deformation monitoring using [[PPP|PS-InSAR]]
- Urban land subsidence analysis using InSAR time series
- Accuracy analysis of [[RTK]] vs [[PPP]] for cadastral boundary
- [[Model Terrain Digital|DTM]] generation from aerial photogrammetry
- Sea surface height monitoring with altimetry
- Cadastral boundary dispute resolution using spatial data

### Thesis Structure
1. Bab 1: Pendahuluan (Introduction, Problem Statement, Objectives)
2. Bab 2: Tinjauan Pustaka (Literature Review) — reference [[Sources]] and [[References]]
3. Bab 3: Metodologi (Methodology)
4. Bab 4: Hasil dan Pembahasan (Results and Discussion)
5. Bab 5: Kesimpulan dan Saran (Conclusion and Recommendations)
6. Daftar Pustaka (References)
7. Lampiran (Appendices — raw data, code, maps)

## KKN Requirements
- Minimum 4 weeks service
- Applied geospatial project with community
- Documentation and report

## Graduation Criteria
- SKS ≥ 144 (minimum, typically 148–160)
- IPK ≥ 2.50 (minimum, typically 2.75+ for honors)
- Skripsi passing (≥ B grade)
- KKN completion

## Thesis Tips
1. Start data collection early (semester 6–7)
2. Use proper [[Least Squares Adjustment]] for all network processing
3. Validate results against known benchmarks
4. Write clearly — readability matters more than complexity
5. Use [[Geodesy MOC]] for literature search and citation context
